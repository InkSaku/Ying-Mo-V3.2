# 映墨手绘 UI

将界面设计为**有页边小剧场的暖纸编辑式界面**：正文像经过编排的刊物，操作像清楚可靠的工具，插画像陪伴工作的轻松旁注。辨识度来自这三者的关系，不来自某张猫图、某个墨团商标或一种固定首页。

本 Skill 是单文件交付：设计规范、证据、CSS、SVG、HTML 和交互示例全部包含在本文件内。只需复制 `SKILL.md`，无需其他配套文件。来源路径仅用于追溯，执行时不要求访问原仓库，不依赖 React、原组件、字体包管理器或原 API。示例 CSS/SVG 可改写为任何技术栈的语义 Token 和组件样式；不要加载原仓库整套 CSS。不要替用户更换产品品牌或增加业务模块。

## 先理解任务，再画页面

开始时明确：用户是谁、首要任务是什么、对象之间什么关系、哪些信息必须同时比较、内容密度和主要设备。已有需求足够时直接判断，不重复索取确认。

1. 按任务组织导航；区分目的地、同页视图切换和一次性动作，不沿用来源项目菜单。
2. 选构图：低频引导用不对称双栏；持续操作用工作主列＋可收起工具；批量比较用账册式行列；长文本用窄阅读列；平级入口可以用开放网格。不同页面不必相同构图。
3. 先摆真实标题、操作、数据及空/加载/失败状态；去掉插画后仍应能完成任务。
4. 再选择一个与当前动作有关的隐喻，为页首或空状态画一个小场景。若会挤压输入、图表或正文，移到边缘或取消。
5. 用同一组 Token 完成至少一个宽屏和一个窄屏方案，再检查浅/深主题、键盘和长内容。

## 七条不可丢失的视觉原则

1. **暖纸承托，墨字主导。** 默认底色 `#f8f7f3`，文字 `#242520`，深蓝 `#334b76` 只负责链接、选中、焦点与小幅图形点睛。纸面不是泛黄做旧纹理；不额外铺噪点。
2. **宋体形成编辑层级。** 展示标题以 400–500 字重和字号建立重心；正文和大部分操作延续衬线。等宽字用于编号、代码、对齐数字；手写字只作非必要短批注。高密度功能区可明确局部换可读 UI 字体，不能把整个产品换成泛化 SaaS 字体。
3. **开放版面先于盒子。** 用对齐、留白、标题和浅纸面区分组，确有必要才加一条细线。列表可有逐行分隔，网格可无边框；不是“每个单元都装卡片”。
4. **操作几何精确，插画适度不齐。** 按钮、表格、字段保持直线、基线和稳定点击区；控件 2px 小圆角，普通内容 0px，浮层可 4–6px。只有图中轮廓、地面线、纸片和短批注可轻微弯斜。
5. **幽默来自动作和比例。** 一个认真做小事的角色，加一件略大的道具、一个轻微意外，例如机器人把最后一块数据片摆歪后扶正。不要用满屏笑脸、彩色贴纸或随机星星替代情境。
6. **墨线疏朗，蓝线点题。** SVG 主线约 1.6px、蓝线约 1.7px，圆端圆接；小猫等小型图有 1.25px 先例。轮廓简洁、内部留空、可有一处实心墨块与纸色表情。UI 图标保持清楚规则，不缩小复杂插画当图标。
7. **趣味服从任务与可用性。** 工作页建议一个主场景，至多一个弱呼应；插画目录可多幅但每格内容有意义。手机先减装饰、再重排布局；焦点、错误、进度、触控面积不缩水。常规反馈 120–200ms，不持续漂浮。

“一个场景”“至多一个弱呼应”是跨产品的默认装饰预算，不是从截图测出的硬限制。若当前任务需要插画浏览页或多步引导，可增加，但不要让表单旁每行都长出角色。

## 交付前检查

- 首屏能识别任务和主操作；每个局部决策区只有一个最强动作。
- 移除装饰后层级仍成立；保留装饰时能解释它与任务的联系。
- 标题/文本/操作对齐，画面不必镜像；每条分隔线都有分组理由。
- 浅色纸面、墨色主按钮、轻宋体、少量靛蓝、小场景相互协调；不同页面没有另立颜色和控件规则。
- 有内容/无内容、有图/无图、长标题、失败和加载都成立；图表坐标、表格数值绝不手绘扭曲。
- 用实测对比度验证文字和必要控件边界，不能把浅装饰线用作唯一输入边界。小型有用文字默认至少 12px，移动输入 16px，操作热区默认 44px。
- 键盘焦点、对话框返回焦点、表单标签与错误、状态播报完整；装饰从可访问树隐藏。
- 说明本次采用哪些源规则、哪些扩展，以及实际验证过和未验证的范围；不要声称静态样例证明了生产交互。

## 01 · 设计哲学

证据标记和 S 编号见第 14 节「研究依据、差异与信息缺口」。

### 准确定位

这不是粗笔涂鸦、新粗野主义，也不是儿童绘本或企业仪表盘换米色皮肤。它是一种**以中文刊物排版为骨架，以细笔日常荒诞为情绪层的工具界面**。[P/C/N S01–S08]

纸面提供连续空间；宋体的大字和松弛行距建立阅读重心；细分隔与小号编号提供秩序；墨色实心按钮使动作明确；靛蓝笔迹把界面和插画联结起来。线稿不是背景贴纸，而像同一页里一件正在发生的小事。移除其一仍可使用，但若去掉宋体层级、开放版面和情境关系，只剩米色背景加插画，辨识度就消失了。

### 手绘感从哪里来

观察墨团形体并非规则圆形；耳朵、书架、信封和纸页的两侧不完全平行；地面线轻微拱起；道具用少量独立路径交代，不做逼真透视。圆头细线稳定，不是噪声抖动。角色往往是一块实墨，周围道具却是空心，形成局部视觉重心。[P/C S03 S04 S05]

UI 本身没有同等不规则：输入底线、网格边界、按钮基线是精确的。手工感与工具的可靠感分处不同层级，这种张力比“所有边框变波浪”更重要。[P/C S02 S08 S09]

### 幽默的来源与限度

- **比例错位**：小鸟搬比自己大的信封、角色抱着大书、口袋装下一本书。[P S04 S05]
- **认真而笨拙的动作**：扶书、托火花、用叶子避雨，角色没有夸张大表情。[P S03 S05]
- **物件替代**：茶杯的热气变对话，地图路线绕一下来到茶杯。幽默在理解关系之后出现。[P S04 S06]
- **允许停顿**：“还没写完，也很好”这类旁注减轻压力；实际操作文案仍直接说明动作。[P S04；跨业务措辞 E]

新产品的失败、计费、权限、删除、数据风险先用明确语言，不能用“机器打瞌睡了”代替错误原因。可在低风险等待或空状态加入温和隐喻；不嘲笑用户，也不伪造任务已完成。

### 为什么轻松但仍专业

专业性来自对齐、可扫读信息、稳定控件、可见反馈和较少视觉噪声；轻松来自字号/留白的节奏、略带失衡的插画、非命令式短文案。它不依赖炫技动效，也不要求每一页都讲品牌故事。高密度工作区可以几乎没有插画，只需在入口或空状态留下相同笔触。[P/C S06 S07 S10]

### 不变量与变量

| 层级 | 应保留 | 可调整 |
|---|---|---|
| 基底 | 暖纸/暖炭与墨字的温度，低饱和 | 同色系表面层级；满足对比度的局部修正 |
| 表达 | 衬线展示层级、轻字重、少量蓝色批注 | 文种字体、标题大小、长阅读/密集工具字号 |
| 组织 | 空白与对齐先分组，必要时单条线 | 导航方向、栏数、页面宽度、比较密度 |
| 操作 | 几何清楚、细边界、小圆角、可见焦点 | 目标栈组件库、原生控件、行为实现 |
| 图形 | 稀疏圆头线、情境关系、少量蓝线 | 角色、道具、行业主题；可完全没有墨团/猫 |
| 情绪 | 陪伴、轻微幽默、不催促 | 文案语气随产品严重程度减弱趣味 |

不要把设计哲学误译成强制“书房”“纸页”“今日”“慢慢来”等产品术语。一个监控平台的异常列表必须直接叫异常列表。[E]


## 02 · 视觉语言与风格边界

### 层次和面积

[P/N S02 S06 S08] 大面积是连续暖纸；其次是墨字与内容影像；靛蓝是稀疏标记。**建议**无照片/图表的 UI 区域以纸与留白占约 80–90%，文字/线/墨块占主要剩余，蓝色可见面积控制在约 5% 内。[E：构图预算，不是像素统计，也不约束真实照片和数据编码。]

表面只有明确功能才分层：页面纸底、稍亮浮层、稍深分组底。不要给每个 section 一种近似米色；同一组件两处出现时应使用同一语义变量。

### 有秩序的不对称

主次宽度可以 1.7:1，也可以主工作列加窄工具列；不把比例定为产品无关硬模板。[C S06 S07] 用共享左边界、基线、固定组间距稳定版面，再改变标题与图形的尺度。允许图内歪斜，不能以随机 padding 或旋转整个卡片制造“自由”。

展示区可有一大一小的图文组合，首要任务区则保持连续。小字眉题、大标题、短说明、操作的相对层级比巨大 Hero 更有辨识度。工作页不要把主任务推到首屏之后。[N S01 S02 S08]

### 边框、阴影和材质

- 默认内容容器无边框、无阴影、直角。行列表需要分隔时使用 1px 装饰线。[D/C S01 S06]
- 字段和可选择项可有完整边框；卡片是组织单元，不自动意味着浮起来的盒子。[C S08 S09]
- 2px 控件圆角、0–4px 表面细微圆角属同一近直角家族；统一示例取内容 0、控件 2、浮层 4。不为所有数值差异增建 Token。[N S02 S06 S08]
- 浮层允许轻阴影，纸面内容不允许悬停升空。来源有书册厚度、浅拼贴投影，这是具体物件表达，不是全局卡片阴影。[P S11；N]
- 纸感主要由色温、宋体、空间产生。没有充分证据支持全站做旧纹理、撕纸边缘或铅笔滤镜。历史水墨栅格素材不是当前所有插画的笔法。[P/C S02 S12]

### 图文关系

标题和说明与插画共享一个语义：文字说明任务，插画提供同一动作的生活隐喻，不逐字画图。插画旁留空，不压在字段/数值/标题后。插画可位于页首右侧、空状态上方、引导说明旁、长内容结尾。允许插画目录多幅并排；不要把这种目录页频率复制到管理表单。[P S02 S04 S08]

手写短句是可选历史表达资源，不是每屏必需。中文功能信息不能依赖西文 cursive 字体。真实内容照片保持原色；只对明确策展/品牌影像使用黑白，不为统一皮肤破坏内容意义。[D S01；P S12 S13]

### 深色模式

同一构图反转为暖炭纸 `#20231f`，字和墨块变浅纸 `#e5e5dc`，蓝线变浅 `#9cb4db`；角色表情用背景色镂出。不能简单 invert 整张截图或 SVG；真实照片不反相。厚重黑面板、发光蓝线不是这套夜间风格。[C/P S02 S04 S08]


## 03 · 色彩与设计 Token 规范

### 比例与定制

[P/N] 纸面与留白占主体，深色字/线形成信息，蓝色占少数。约 80–90% 纸面、蓝色约 5% 内仅为**无媒体界面的构图建议 E**，不作为截图检测阈值。图表、照片、业务风险色不受这个面积预算硬限。

固定风格色是纸、墨、蓝及其夜间版本。允许补充品牌商标颜色、警告和多类别图表色，但应限定在对应语义范围，并为两主题测试；不自动把导航和所有按钮染成业务颜色。高风险状态的可读性和行业语义优先。[E]

### 数值如何取舍

- 间距来自 D S01 的 `4/8/12/16/24/32/48/64/96px`，与常用工具默认阶梯的重合不代表套模板。代码有 18、28、42、56 等局部值；不宣称全站严格八点网格。[N]
- 1280 容器、720 阅读、430 小表单取自 D S01；代码存在 1120 内容基数、1248 外壳、800 阅读、368 登录、780 工作画布。示例按**角色归一化**，不说这些是同一个最终全局值。
- 字号以 rem 表达，不锁死根字号。页标题 32–48、展示 40–56 的 `clamp` 公式为 E，端点参考实际范围。
- 默认普通内容 0、控件 2、浮层 4px，保留近直角家族。代码里未收敛的 9–10px 菜单圆角不是本系统推荐。
- 默认卡片阴影 none；浮层阴影来自 header menu。深色阴影改用黑色为 E，避免随墨色变亮形成光晕。

## 04 · 字体与排版

### 字体来源

[C S14] 实际入口加载 Noto Serif SC Variable 与 JetBrains Mono Variable；全局 `--sans` 甚至别名指向 serif，说明衬线不只用于标题。[C S09] 英文小眉题有 Georgia，手写装饰使用 Snell Roundhand / Segoe Script。没有随 Skill 分发这些字体。

[N] 默认展示与正文共享中文宋体，fallback 见 tokens.css。选字体须覆盖目标语言；英文产品可用目标环境可用、许可明确的书刊衬线，但保留轻字重和字面节奏。不要以系统 fallback 截图声称验证了 Noto Serif 的实际字形。西文手写字体通常不覆盖中文；中文批注保持宋体或专门选择有授权的中文手写字体。[E]

### 角色尺度

| 角色 | 推荐桌面 / 手机 | 字重 | 行高 / 字距 | 来源与取舍 |
|---|---|---|---|---|
| 品牌字样 | 72–112 / 58–72px | 400–500 | 1.1–1.25 / .04–.08em | D S01；C S09 的 112/66；仅引导页 |
| 展示标题 | 40–56 / 32–40px | 400 | 1.25–1.4 / .04em | N S01/S06，不要求每页巨大 |
| 工作页标题 | 32–48 / 28–36px | 400–500 | 1.35–1.6 / .015–.04em | N S02/S07；tokens 默认 32 起，可为密集页下调 |
| 区块标题 | 22–30 / 20–26px | 400–500 | 1.35–1.55 / .02em | D/C S01/S06/S08 |
| 列表标题 | 17–24 / 17–21px | 400–500 | 1.45–1.6 / .02em | D/C S01/S06 |
| 连续正文 | 17–19 / 16–18px | 400 | 1.75–1.9 / .01–.02em | N S01；S07 专用阅读 19px/2.05 是可选宽松变体 |
| 操作正文 | 14–16 / 14–16px | 400 | 1.55–1.75 / .02em | D S01；来源有更小控件，本版提高可读性 |

不是强制数学比例尺：读写任务的标题可以只比正文大约 1.8 倍，展示入口可达 3 倍。层级靠字号、空间和位置，避免到处 700 粗体。偶尔需要强调时 500 即可；真实字体无 500 时不要伪造细节导致字重混乱。

### 中英文和数字

- 中文正文默认 `.02em`，英文正文通常正常字距；不要给 URL、代码、连续数字套中文宽字距。[N/E]
- 中文使用中文标点；单位和标点与相邻数字保持不错误拆行，日期可用不换行局部片段；长标题仍自然换行。[E]
- 表格数字右对齐，`font-variant-numeric: tabular-nums`；编号/时间戳可以 mono，不把整段中文说明换等宽。[D/C S01 S10]
- 英文眉题大写和宽字距只作二级索引。核心功能名称不能依赖模糊的小英文装饰标题。
- 长文本用合适行长而非缩字号；无封面/无副标题时收掉空位，不固定标题高度。
- 允许局部 `--ym-font-functional` 用于高密度数据网格、终端或字形覆盖不足的文本，说明范围；标题、页首和周边编辑层级仍延续衬线。[E]

### 字体工程

按产品实际文字范围选择合法字体与子集，使用 `font-display: swap`，仅预载首屏必要字重/子集，不下载整套中文字体做装饰。先测试 fallback 的换行和控件宽度，再测试目标字体加载后没有裁字。字体切换不得改变字段标签或状态区域的可发现性。[E；来源加载方案不是跨栈依赖]


## 05 · 布局与空间节奏

### 页面尺度不是固定模板

[D S01] 1280px 是设计规范的内容上限、720 阅读、430 表单。[C S10] 基础代码实际使用 1120 内容基数及加 128 的外壳；[C S07] 新阅读可扩到 1560 外壳/1360 内部，正文上限或自适应列又不同。故 tokens 选择语义角色，而不复刻某个页面外壳。

[N] 常规产品从 1280 上限开始；正文 640–800（默认 720），短表单 368–430，持续工作画布约 780。需要横向比较的数据界面可增宽至 1440 或全宽 [E]，仍保留稳定边距，文本说明不随之无限加长。不要把 430 强制给多列设置表单。

### 四种可迁移构图

| 模式 | 适用任务 | 组织方法 | 对应证据 |
|---|---|---|---|
| 编辑式开场 | 首次理解、低频引导、介绍工具 | 主标题/说明与较小插画形成非对称双栏；下方直接出现可用操作 | S09 登录双栏、S13 首页；只提取主次关系 |
| 工作主列 | 输入、生成、配置、持续编辑 | 输入/结果占主空间；次要参数按需展开或置窄栏；反馈靠近动作 | S07 单栏画布、S08 参数分组 |
| 开放目录/网格 | 平级入口、资源选择、内容浏览 | 2–3 列无外框，统一标题基线；列表以必要横线维持扫描 | S04 入口网格、S06 无边框网格 |
| 账册比较 | 指标、状态、记录、批量操作 | 窄导航/筛选＋主表格；指标同行而非多层卡片；数字和操作独立对齐 | S02 管理指标、S08 队列、S10 列表；复杂数据表为 E |

选择基于任务，不为不同产品预置相同的 hero＋三卡片＋定价区。两列可以等宽，规则网格也可以对称；反对的是所有页面为了模板整齐而失去信息主次。

### 空间节奏

[D/N S01] 推荐阶梯 4/8/12/16/24/32/48/64/96px：文字内部 8–16、控件内部 12–24、平级单元 24–32、区块 48–64、展示留白可 96。来源实际有 28/42/56；若视觉与内容需要可局部使用，不假称存在严格全局倍数律。

- 桌面边距 48–64，平板约 32，手机 20–24。[D/C S01 S06]
- 同组标签到字段 8、字段到下一字段 24、组到组 32–48 为跨产品归一化起点。[N]
- 主标题和主要操作共同形成视觉重心；插画朝向/蓝线可把视线带回任务。
- 一处边界只用一条必要线。标题底线、容器顶线、列表首行线重叠时删掉冗余层。
- 同列的基线与起点准确；图内可偏斜。不要用随机 `rotate` 或 margin 破坏阅读顺序。
- 网格子项使用 `minmax(0,1fr)` / `min-width:0`，长内容换行；操作组可 wrap。没有内容的非必要区块不造空盒补位。

### 信息密度

展示/引导页可以松，日常工具页把留白放在组间，组内保持紧凑。列表一行可用 20–28px 上下内距；数据表可 12–16px 单元格间距 [N/E]。不是所有管理界面都要加大字号和大插图；稳定的纸墨基底、宋体页标题、蓝色选中就足以联结风格。

功能密集时依次减少装饰、收起低频参数、降低组间空白，再考虑局部紧凑字号。不要先把正文压到 10px。


## 06 · 通用组件语言

这是视觉与行为约束，不是来源业务组件库。默认继承 tokens.css：ink 文本、paper 页面、surface 浮层、accent 选中、control-line 必要边界、line 装饰分隔。所有尺寸为 CSS px；来源有更小功能字，本 Skill 默认控件 14–16、辅助字 ≥12。[N/E]

共同状态：hover 有轻微文字/底色/边界变化；focus-visible 为 2px 蓝色实线、外偏 3px；active 可下移 1px；disabled 保留说明、禁止交互并使用原生属性；loading 保留控件宽度、明确处理中并防重复提交。鼠标 hover 不是唯一可发现状态。静态 CSS 不能代替键盘/焦点/状态逻辑。

### 1. Buttons [C/N S02 S09 S10]

- **视觉/结构**：短动作名称＋可选方向箭头，主按钮墨底纸字；次按钮透明底，文字按钮无容器；同一决策区一个最强动作。
- **尺寸/颜色/边界**：默认高 ≥44、内距 8–12 × 14–20、内容 gap 8，2px 圆角；次按钮 1px control-line。入口大按钮可高 50。危险动作才用 danger，不用蓝底主按钮。
- **状态/响应**：hover 墨色混纸 14%，focus 蓝圈；disabled 可 .55 透明度但旁侧原因文字保持可读；loading 替换动作文字并 `aria-busy`。手机可满宽；长标签可换行，不截断操作含义。
- **错误**：所有按钮胶囊化、悬停升空、多个同强主操作、把装饰箭头当唯一名称。不能用 a[disabled] 假装禁用。

### 2. Cards [P/C/N S04 S06 S08]

- **视觉/结构**：首先是“标题＋内容＋必要元信息/动作”的单元，不默认画外框。连续项用行式；可比较的平级入口用开放网格；可选对象才用完整选择边界。
- **尺寸/颜色/边界**：无框单元 gap 24–32；浅底重点单元内距 24–32；paper/soft，圆角 0（重点纸面可 2–4），无阴影。需要边界才 1px，不能四周框再套框。
- **状态/响应**：可点击整格必须一个清楚原生链接，焦点覆盖单元；有多个动作时标题链接与按钮分开、不嵌套。选中用蓝线＋勾。3→2→1 列或按最小内容宽度减少列数。
- **错误**：每个指标装浮卡、统一高度强行留空、全卡片 hover 位移、给每项一幅大插画。

### 3. Inputs [C/N S09 S08；边界修正 E]

- **视觉/结构**：label、字段、help/error 三段；轻量搜索/短单字段可底线，复杂配置使用完整矩形框。
- **尺寸/颜色/边界**：高 48，内距 10–12；纸/透明底、ink 字、2px 圆角。唯一识别边界用 control-line；line 只适合装饰。多行文本至少约 120 高为 E，允许纵向 resize。
- **状态/响应**：焦点外圈＋蓝边，错误 danger 边＋文字并 `aria-invalid`/`aria-describedby`，不是只变红；disabled/read-only 要区分。手机输入 16px，日期/文件等优先原生可访问实现。
- **错误**：placeholder 代替 label、过浅下划线、去掉 outline、为了手绘扭曲边框、固定高度裁掉多行内容。

### 4. Forms [P/C/N S07 S08 S09]

- **视觉/结构**：按用户决策分 fieldset，说明与标签直接相邻；低频高级参数可展开，核心字段始终可发现。
- **尺寸/颜色/边界**：小表单 368–430 宽；复杂工作表单可更宽；字段间 24、组间 32–48；组标题 20–26。整体通常无框，必要分组用一条线。
- **状态/响应**：提交区反馈与动作相邻；错误保留输入并定位字段；处理中有文本而非角色动画代替。手机变单列、次操作换行，底部固定区需预留安全区与正文空间。
- **错误**：每组一个大卡片、所有字段并排、插画挤进输入区域、以诗意文案隐去错误或删除结果。

### 5. Navigation [P/C/N S02 S10]

- **视觉/结构**：文字导航＋少量线性图标；顶栏轻薄，任务型界面可用窄侧栏；导航项源于目标产品任务。
- **尺寸/颜色/边界**：顶栏参考 68 高，侧栏参考 176–210 宽；链接视觉文字 14、可触热区 ≥44；ink/muted，当前项 accent＋短底线或侧边 2px 线，避免只靠颜色。
- **状态/响应**：用 `aria-current="page"`；hover 加深或下划线。平板侧栏收为明确目录入口；移动端可顶栏/底栏/折叠菜单，按真实频率选择，不强制原项目四入口。
- **错误**：移植来源菜单、胶囊主导航、让菜单隐藏核心动作、只在 hover 展开且键盘无法打开。

### 6. Tabs [C/N S08 S10；完整键盘模式 E]

- **视觉/结构**：同一对象的互斥视图，文字横排，当前项短蓝底线；页面路由链接不要冒充 ARIA tabs。
- **尺寸/颜色/边界**：高 ≥44、横向间距 16–24；文字 14、2px 选中线；其余无底盒。也可用轻纸色当前项，需有额外选中标记。
- **状态/响应**：真正 tablist 实现左右键/Home/End、roving tabindex、tab/tabpanel 关联；等待网络时可手动激活。手机行内滚动并把当前项带入视野，不能压缩每项到不可触。
- **错误**：所有项墨底、当前项只差很浅颜色、把带多个可交互子元素的卡片声明为 tab。

### 7. Menus [C S10；N/E 统一外观]

- **视觉/结构**：触发器＋贴近触发器的纸面浮层＋纵向选项；选值优先原生 select，动作菜单和 listbox 不混用。
- **尺寸/颜色/边界**：建议 min-width 220（来源定位逻辑）、内距 8、行高 ≥44；surface、1px control-line、4px 圆角、轻浮层阴影。视口边距 ≥8。
- **状态/响应**：hover/键盘活动项 soft，已选项 accent＋勾；展开箭头转动 160ms；支持 Escape、方向键、选择后还焦点。手机浮层可重新定位或底部面板，内容可滚动且不被键盘遮挡。
- **错误**：复制旧菜单 10px 圆角当全局原则；自制只支持鼠标菜单；固定宽度溢出；滚动页面时浮层与触发器脱节。

### 8. Dialogs [C/P S08 S10；N]

- **视觉/结构**：标题/说明、决策内容、操作尾部；重大决策文字清晰，插画可省略。
- **尺寸/颜色/边界**：普通约 480 宽、复杂可 760–970；内距 24–36；surface/paper，1px line，4px 圆角或直角；阴影仅用于覆盖关系。两栏内容 gap 32。
- **状态/响应**：受控打开、初始焦点、安全取消、Tab 留在模态内、Escape 和关闭按钮、返回触发器；背景 inert。手机约 20 内距、单列、max-height 视口内、内容滚动、尾部不能遮最后字段。
- **错误**：放大品牌图而压缩决策内容、无标题关联、只靠遮罩关闭、忙碌状态丢失反馈。来源有焦点处理先例，但不能视为所有 edge case 都已解决。

### 9. Tooltips [E 扩展设计建议]

- **证据范围**：代码检索未发现一套统一 tooltip 组件；原生 title 不能证明完整规范。
- **视觉/结构/尺寸**：触发目标＋短解释，surface/ink、1px control-line、4px 圆角、8×12 内距、12–14 字、建议最大 240 宽，轻阴影。可与菜单共用表面。
- **状态/响应**：hover 和 focus 均能显示，Escape 可关闭，可悬停其内容且不立即消失；触屏重要说明改为行内 help 或信息按钮弹层。tooltip 本身不放链接和按钮。
- **错误**：必要信息只藏 tooltip、触控无入口、黑色巨大气泡、用俏皮文案代替字段定义。

### 10. Badges [C/N S08 S10]

- **视觉/结构**：短状态词或数量，纯文字/前缀/小矩形为主；圆点仅作为冗余状态提示。
- **尺寸/颜色/边界**：12px 起、内距 2–4 × 6–8，0–2px 圆角；中性 soft 或透明；状态用 success/danger 等；不把所有标签染蓝。
- **状态/响应**：非交互 badge 无 hover/focus；可移除标签的删除按钮有名称及 ≥44 热区。手机长标签换行、数字不覆盖导航。
- **错误**：胶囊泛滥、9px 必要说明、只有红/绿点没有文字、把状态误画成可点击按钮。

### 11. Notifications [C/P S08 S10]

- **视觉/结构**：行内反馈优先，内容为状态＋说明＋必要动作；通知列表可未读浅底和细侧线。
- **尺寸/颜色/边界**：行内内距 12–16、字 14，局部低饱和状态底；细 1–2px 侧边界或整体单框，不做全屏彩条。Toast 位置、寿命无充分统一证据，属于 E。
- **状态/响应**：普通更新 `role=status`/polite；紧急失败 alert，避免反复播报；可恢复错误持续显示，提供关闭或重试。手机与固定导航、安全区、键盘避让。
- **错误**：成功只演动画不说结果、错误几秒后自动消失、每次轮询弹一条 toast、把幽默置于实际诊断之前。

### 12. Empty States [P/C S02 S04 S10；N]

- **视觉/结构**：一个有语义的小场景＋明确空的原因＋下一步；例如“尚未连接数据源／连接后显示趋势”，而非“这里空空如也”。
- **尺寸/颜色/边界**：图约 128–180、标题 20–26、正文 14–16；垂直内距 28–32，图下 18–24；背景通常透明，无浮卡，必要时一条分隔。
- **状态/响应**：区分首次空、筛选无结果、无权限、失败；可用动作原生按钮/链接。窄屏缩图到 96–128；嵌套局部空状态只留文字，避免重复场景。
- **错误**：假数据填空、每个空区插同一吉祥物、拿断线错误当“没有记录”、把插画设为必要标签。

### 13. Loading States [C S10 S08；N/E]

- **视觉/结构**：短加载为文字和局部 busy；整页骨架对应真实标题/正文轮廓；长任务用阶段、已处理量、取消入口。
- **尺寸/颜色/边界**：骨架 soft、0–2px 角；来源行 14、标题 42、块 260 只反映特定页面，迁移时按最终内容形状决定，不统一固定高度。
- **状态/响应**：`aria-busy`、一次 polite 状态；骨架装饰 hidden；真实 progress 才显示百分比，不编造进度；保留旧内容可减轻闪烁。手机骨架按移动布局重排。
- **错误**：高亮 shimmer、无限漂浮角色、每 100ms 播报进度、减少动态后消失所有“正在处理”信息。

### 14. Tables [C 部分 S10；E 复杂数据表扩展]

- **证据范围**：来源正文表格、账册式指标/管理行可参考；没有完整复杂数据网格规范，排序/冻结/多选不能说已从原型提取。
- **视觉/结构/尺寸**：原生 table/caption/thead/th；正文 14–16、单元格内距 12–16、数字右齐、表头 500；背景透明，1px 横线，必要时 soft 表头；坐标和表格边线严格几何。
- **状态/响应**：排序用带名称按钮与 aria-sort，选中蓝侧线/勾/浅底；hover 轻底，焦点可见。手机优先级明确时可列转键值；需比较的数据保留表格并局部横向滚动、可键盘聚焦和提示，不能整页溢出。
- **错误**：手绘数据曲线、粗边框监狱式网格、删除重要列、用卡片强行拆散必须跨行比较的信息。

### 15. Lists [C/P S02 S06 S10；N]

- **视觉/结构**：标题/摘要为主，元信息和操作各有对齐区；编号仅在顺序有意义时出现。
- **尺寸/颜色/边界**：条目纵距 20–32，必要细横线；ink 标题、secondary 正文、muted 元信息；通常无单项底盒和阴影。
- **状态/响应**：标题明确可点击，行内多动作独立；hover 不移动整行；选中有非颜色提示。手机元信息下移、缩略图移正文下方，操作 wrap，顺序与 DOM 一致。
- **错误**：每层都加横线、所有条目显示无意义序号、整行点击与复选框互相冲突。

### 16. Search [C/P S06 S08 S10；N]

- **视觉/结构**：有可访问 label 的 search 输入、搜索/清除、结果数、活动筛选；复杂筛选按需展开。
- **尺寸/颜色/边界**：输入高 48，按钮 ≥44，间距 8–12；短查询底线、复杂过滤整框；图标 18–20，不能替代标签。
- **状态/响应**：提交/实时搜索反馈明确，异步显示 busy；组合输入法期间不抢提交。窄屏查询在前，筛选和动作换行；无结果提供清除条件。自动完成键盘模式为 E，需使用成熟实现。
- **错误**：只放放大镜没名称、只有 hover 能清除、每次输入移动布局、空结果硬铺一堆空卡。

### 17. Pagination [C S10；N]

- **视觉/结构**：上一页、当前位置/总页、下一页，或有限数字页链接；不必制造复杂数字条。
- **尺寸/颜色/边界**：顶距 32–48（源 44）、gap 12–18、操作 ≥44；透明细边框、当前页蓝线或墨字，数字 tabular。
- **状态/响应**：边界项 disabled；加载期间保留当前位置；变化后让用户找到结果起点并适度播报。手机允许换行，保留前后动作，不压缩热区。
- **错误**：无限小页码、假装一页也需分页、点击后焦点丢失、用翻书动画延迟结果。

### 18. Selection Controls [C S08；N/E]

- **视觉/结构**：原生 checkbox/radio＋完整文字标签；单选互斥组有 legend。可选纸面单元也要明确 radio/checkbox 语义。
- **尺寸/颜色/边界**：控件可见形约 16–18、label 行 ≥44、间距 8–12；accent 选中，control-line 边界，勾/圆点保留几何准确。
- **状态/响应**：整标签可点，键盘原生行为；错误在组说明显示，disabled 说明原因。手机每行一项或宽松 wrap，不把点击区缩成小方块。
- **错误**：用手绘圈遮盖原生焦点、仅颜色区别选中、交互标签和装饰标签完全同形且无状态。


## 07 · 手绘插画系统

### 观察到的三支家族

1. **墨团情境**：一块偏斜、略有梨形的不规则墨色身体/头部，纸色短眼线和微笑；细线手脚和轮廓道具，少量靛蓝动作线。[P/C S03 S05]
2. **纯物件关系**：书页、铅笔、茶杯、鸟、口袋等可独立成景，不必有墨团。幽默通过物体关系表达。[P/C S04 S06]
3. **线描小动物**：不齐耳朵、弯尾、局部墨耳/鼻、蓝色书签；细节稍多但仍保留大块内部空白。[P/C S05]

共同点是墨线、空白、情境动作、局部蓝线。复制品牌墨团或猫不是迁移必要条件；新的机器人、计时器、抽屉、数据苗圃可以沿用语法。

### 几何与笔法

| 属性 | 观察值/规则 | 使用方法 |
|---|---|---|
| 画布 | 多数 320×210，spark 原图 320×220；生产版也有裁切 viewBox | 新场景默认 320×220 [N]；按最终显示宽度裁去多余空白 |
| 主轮廓 | 1.6px，圆端圆接；猫 1.25px | 场景 1.6；小型高密图适当减细，不混成粗描边漫画 [C] |
| 蓝色线 | 1.7px | 只点题：路线、书签、被操作物、短运动线 [C] |
| 不规则 | 路径端点略偏，地面轻弯，左右不镜像 | 每个主要道具一两处几何偏差即可；建议偏差 1–4/320 单位、局部倾角 2–6° [E]，不是所有控制点抖动 |
| 填充 | 道具多为空心，墨团实心，表情纸色 | 新图最多一处主要实墨锚点为默认 E；不用灰色体积渐变 |
| 细节 | 短线说明纸张/表情，背景稀疏 | 96px 缩略图仍能读动作；建议一个主体、1–2 道具、0–3 小强调 [E] |
| 地面 | 单条略弯细线，部分图有短波纹 | 让角色站稳；不是强制所有图都有底线 [P/N] |
| 比例 | 角色常比道具小，四肢细 | 可将道具设为主体高度约 1–1.8 倍作起点 [E]，以动作能读懂为准 |

描线保持干净。不要给所有路径加 turbulence、roughness 滤镜或多重虚影；原图的手工感来自设计路径。描边可 `vector-effect: non-scaling-stroke`，这是源 `ink-sketches.css` 的策略；但小于 96px 时需另做删细节的简版，固定描边否则会堵住内部空隙。[C/N]

### 从新主题生成新图

1. **写一个动作**，不先列行业图标：“整理输入”“检查异常”“等候结果”“完成一组任务”。
2. **把动作转为可见道具关系**：整理→小机器人扶齐数据片；检查→拿尺对齐倾斜小柱；等待→计时器旁一颗尚未落下的点；完成→笔把最后一个勾当成小旗。
3. **只设一个轻微意外**：最后一张片有点歪、量尺比角色高、小点在杯沿歇脚。避免夸大故障或暗示真实数据已成功。
4. 先画黑白 silhouette 和关键路径；删掉非动作必需的细节。控制人物表情只需两短线/点和一条口线。
5. 加蓝色关系线：表示被整理的片、数据线的连接、完成勾。它不是填满的科技蓝面罩。
6. 将插画放到标题旁或空状态，检查视线是否回到操作；在 96/160/240px 和两主题观察，必要时出简版。

**AI 工具**：机器人可以是不齐的小矩形头，墨色面板纸色眼睛，线性四肢；捧数据片、解开一根线路，代替发光脑、渐变球、全息电路。

**效率工具**：小计时器坐在任务清单旁；最后一条短线形成勾。等待使用静态姿态＋真实进度文案，完成使用状态文字＋一次短反馈。

**数据平台**：角色用尺扶齐小柱或给一颗“数据种子”浇水。此图只能在说明/空状态区域，真实柱图保持精确几何和比例；不可把幽默形态当数据编码。

这些均为 [E]，不是原仓库已有插画。新 SVG 示例见第 15 节内的 `illustration-examples.svg` 完整代码块，包含 `ai-sort`、`data-seed`、`task-done`、`task-wait` 四个 symbol，首次独立创作、未拷贝来源路径。空状态使用未勾选的task-wait，完成态才用task-done，不让插画暗示错误的状态。

### SVG 实现约定

```html
<svg viewBox="0 0 320 220" aria-hidden="true" focusable="false">
  <g fill="none" stroke="currentColor" stroke-width="1.6"
     stroke-linecap="round" stroke-linejoin="round">
    <!-- 少量有意弯斜的 path，默认不画背景 -->
  </g>
  <path fill="currentColor" d="…" /> <!-- 可选实心形体 -->
  <path fill="none" stroke="var(--ym-paper)" stroke-width="2.4" d="…" />
  <g fill="none" stroke="var(--ym-accent)" stroke-width="1.7"
     stroke-linecap="round" stroke-linejoin="round"><!-- 点题线 --></g>
</svg>
```

上面是结构说明，不是可直接渲染的完整路径；使用实际示例 SVG 起步。外层继承 `color:var(--ym-ink)`。CSS 变量随内联 SVG 或同源 `<use>` 继承；`<img src>` 独立文档不会继承页面变量，需静态主题资产或内联版本，不能假设夜间自动换色。

- 装饰用 aria-hidden + focusable=false + pointer-events:none；有信息的图用唯一 title/desc ID，并在相邻文字保留信息。
- 多实例 symbol/clipPath ID 加前缀避免冲突；不要插入不可信 SVG markup。
- 为图预留 aspect-ratio，避免加载位移；不嵌字体、照片、base64 位图、脚本或昂贵滤镜。
- 图内不写必要 UI 文本，保持可翻译、可缩放、可读屏。
- 触控/减少动态保持静态；不要为了“活泼”让角色持续巡游。源猫跑步是局部状态触发特例。

### 图文密度验收

一般工作首屏一个主图、最多一个弱呼应 [E]；无图也是合理的密集状态。插画目录可每项一图 [P S04]，各图尺度和基线一致。页首图通常 145–240，手机 96–120；空状态 128–180 [C/N]。较大品牌场景可 260–460 [C S02]，不能复制到每个表单页。若图让首要输入移出首屏，先缩图或移走。


## 08 · 图标系统

[C S10] AppShell 图标使用 24×24 viewBox，移动导航显示 21–22px，描边 1.45、round cap/join、fill none；CustomSelect 的 16px 箭头用 1.5。品牌标记为特殊实心图形，不能当作所有功能图标的范式。

[N] 通用系统统一为 24 单位网格，约 1.5 描边，显示 16/20/24 三档；图形主体留约 2 单位光学余量 [E]。图标线条应与 1.6 场景线接近，但不要因为“同风格”把功能图标弄歪。实心填充用于选中点、勾和少量品牌形体，避免同一工具栏同时混用粗实心、细 outline、彩色 emoji。

| 用途 | 选择 | 原因 |
|---|---|---|
| 搜索、关闭、展开、上传、设置 | 清楚的常规线性图标 | 识别和密度优先 |
| 功能入口的情绪提示 | 适度手绘小图，附明确文字 | 尺度足够且不承载唯一标签 |
| 页首、空状态、低频引导 | 情境插画 | 通过关系和动作表达，详见第 07 节「手绘插画系统」 |
| 状态指示 | 简单勾/点/警示形＋文字 | 不只依靠颜色 |

图标按钮至少 44×44 热区，图形本身不必放大至 44。SVG 装饰 hidden，按钮有可访问名称；常用低频或含糊图标附可见文字。关闭图标不随场景笔法变成歪斜的装饰叉。图标颜色继承 ink/secondary；蓝色用于选中和焦点，不是每个图标都蓝。

手绘小图 48px 以下通常失去情境，先简化成图标或保留文字；不要缩放 320×220 场景充当 16px toolbar 图标。若选用第三方图标集，限定同一线条家族并检查许可，不要求安装特定库。[E]


## 09 · 交互与动态

### 情绪与时间

[D S01] 动效快速、克制、提供反馈；不持续漂浮、视差和无意义逐项入场。[C S10] 按压 100ms、普通样式 160–180ms、菜单进入 140ms；[C S15] 特定共享元素导航 300ms。

| 场景 | 推荐 | 行为与范围 |
|---|---|---|
| hover/focus 色彩 | 120–160ms ease-out | 颜色/底色/边框，不移动布局 [N] |
| 按钮 active | 100–120ms | 可 translateY(1px)，不缩放全卡 [C/N] |
| 菜单/轻浮层 | 140–200ms ease-out | opacity + 0–3px 位移 [C/N]；焦点不等动画 |
| 展开折叠 | 160–200ms ease-out | 内部内容与布局稳定，避免 max-height 大值造成迟滞 [E] |
| 跨视图语义连续 | 300ms cubic-bezier(.22,.75,.25,1) | 仅被选中对象的标题/视觉延续；导航壳不跳 [C S15→N] |
| 拖动反馈 | 随手即时；回位约180ms | 源灯箱 .2,.8,.2,1 曲线，仅相关直接操控场景 [C S10] |
| 角色趣味 | 默认静态 | 若任务确需，可由用户操作触发一次短回应；完成即停 [N/E] |

不要把源小猫 .64s 帧循环和 3.2s 伸懒腰变成所有图形默认时长。[C S05] 源中这些是特定角色状态，且有 reduced-motion 停止规则；本 Skill 不要求复制角色行为。

### 交互状态矩阵

- **Hover**：加深文字/边界或淡纸底；可点击文字必要时下划线。静态插画不响应 pointer。
- **Focus**：2px 实蓝轮廓、3px 外偏，深色改浅蓝；必须在默认和选中底均可见。不可仅复用 hover。
- **Active/selected**：蓝色短线、勾或状态文案＋低对比底；按钮按压不使邻近元素挤动。
- **Disabled**：真实 disabled；若使用 aria-disabled，则代码阻止执行且保留可理解原因；透明度不作用于原因说明。
- **Loading**：保留上下文、按钮尺寸和输入；明确正在处理，防重复提交，长任务允许取消/查看进度。骨架可静止。
- **Success/error**：文字先说实际结果，再可有温和图形；反馈就近，不能靠短暂动画或 toast 承载唯一结果。

展开按钮使用 aria-expanded/aria-controls；真正模态对话框管理初始/循环/返回焦点，背景不可交互。切页保留用户上下文（筛选、返回位置），不等待装饰完成才显示内容。[C S10，通用化 N]

### 减少动态与性能

`prefers-reduced-motion: reduce` 时去除移动/角色帧/共享元素/自动滚动，保留即时颜色与状态文字。不要用动画结束事件驱动核心提交或关闭逻辑。只动画 opacity/transform 等适合属性；避免给所有元素 transition:all 或常驻 will-change。需要宽高变化的折叠应有可访问的无动画退化。[E]

“动画符合风格”不等于每个页面必须有动画。数据密集屏和长表单静态即可。


## 10 · 响应式设计

### 证据与归一化

[C] 原代码存在 380、640、767、979、1100、1199、1360 等断点，分别服务表单、网格、导航、阅读栏，不是统一设备字典。[P] 所存截图覆盖 320/350/390 与 1280/1440/1680；长截图的长度不是页面首屏设计高度，部分截图临时隐藏固定导航，不能据此判断固定区遮挡。[D S04 S07]

[N/E] 跨产品用内容容量决定断点。下面 640/980 是默认设计讨论边界，不禁止按实测改变；CSS 中媒体查询不能直接使用普通 var()，需在目标构建工具映射或显式书写。

| 职责 | Desktop ≥980 | Tablet 640–979 | Mobile <640 |
|---|---|---|---|
| 容器 | 常规1280上限、48–64边距 | 32边距、主区优先 | 20–24边距；320px可取20 |
| 开场 | 标题＋一侧插画，不必满屏 | 缩短文案宽度，图120–160 | 标题优先，图96–120或下移/隐藏 |
| 开放网格 | 3列或按内容最小宽度 | 2列 | 1列；轻标签可自然换行 |
| 工作区 | 主列＋窄参数/检查区 | 辅栏折叠，避免两列都过窄 | 任务顺序单列；高级参数disclosure |
| 导航 | 顶栏/窄侧栏 | 收侧栏，保留当前位置 | 按频率选顶/底/折叠菜单；不照搬原业务入口 |
| 文字 | 页标题32–48，正文16 | 收标题，正文不缩水 | 标题约28–36；输入16；辅助≥12 |
| 数据比较 | 多列账册 | 缩低优先级说明，不先删数据 | 键值重排或局部横向表格，不全页横滚 |
| 操作 | 本地决策区一个主操作 | 动作可wrap | 44px热区；需要时满宽，保持取消可见 |
| 弹层 | 受控宽度与高度 | 重定位防溢出 | 单列可滚动，max-height基于dvh并扣边距 |

### 转换顺序

1. 判断小屏仍需同时看到的内容，例如查询和执行、指标与时间范围。保留任务关系。
2. 降低辅助内容的空间预算：隐藏重复眉题、缩图、收起高级参数，不能隐藏错误或主要动作。
3. 多列按语义重排。用合理 DOM 顺序，再用 Grid 摆宽屏；不要让 CSS order 造成屏幕阅读器与视觉顺序冲突。
4. 导航是否改底栏取决于目标产品的稳定高频入口。高密度工具也可用清楚的展开菜单，不继承来源的固定四项导航政策。
5. 需要固定操作栏时预留其高度和 env(safe-area-inset-bottom)，在软键盘打开时仍看得到聚焦字段；相关策略需真机验证。

### 内容边界条件

- 长中英文名称、URL、数字单位、长操作文案自然换行；只有明确存在完整查看方式的次要摘要可省略。
- 不使用固定画面高度模拟整页；min-height需可被真实内容撑开。
- SVG预留比例、不拉伸；小图删细节，不把整个场景无限缩小。
- 图表文字不随整图缩到8px；窄屏减少刻度、保留数据可查看或表格替代。[E]
- 200%文本放大仍可操作；320px无整页横向滚动。表格/代码等二维内容可在标明用途的区域局部滚动。

### 验收矩阵

至少320、390、768、1440 × 两主题；检查长标题、加载、失败、空数据、有图/无图。用键盘走主任务；验证焦点未被sticky区挡住。触控机测试软键盘与安全区，不能仅靠桌面截图宣称完成。静态示例验证范围见cross-scenario-validation.md。


## 11 · 可访问性

来源 D S01 已明确可见焦点、44×44触控、语义、错误关联和 reduced-motion；C S10 含实际 busy/live region、对话框焦点处理。以下是跨产品规范，不是原项目无障碍认证。

### 颜色

普通文字至少4.5:1，大字至少3:1；必要控件识别边界及非文本状态图形与相邻色至少3:1。装饰线不用为了达标全部加深，但不能用它作为字段唯一边界。相关解释见 《WCAG文字对比》 与 《非文本对比》（2026-10-15查阅）。

源muted在paper上约4.57，低透明度会使其不合格；soft面用更深muted-on-soft。必要边界用control-line，不用line/line-strong；实测值见design-tokens.md。状态颜色带文字/图形，图表加线型/标记/直接标签，不把红绿区分当唯一编码。

### 操作与语义

- 默认操作目标至少44×44，是来源产品规范与本Skill的实用目标；不要误写成WCAG 2.2 AA所有目标一律44px。AA的目标大小条款是24×24并有例外，见 《Target Size Minimum》。
- 使用button、a、label、fieldset/legend、table、dialog等正确语义。div的点击事件不自动获得键盘操作。
- 为所有输入提供持续可见标签；错误通过aria-invalid和aria-describedby关联。placeholder只举例，不作唯一说明。
- 焦点2px实线且可见；不能被overflow裁切或固定栏遮挡；页面提供跳转主内容入口。自定义tab/menu需要完整键盘模式，否则优先原生。
- 模态打开后有可理解的初始焦点、Tab不进入背景、Escape/关闭入口、关闭还焦点；不可删除焦点轮廓后让插画“指出”焦点。
- 普通状态用polite/status，紧急错误alert；不把高频进度和装饰反复读出。loading骨架隐藏而保留状态文本。
- 装饰SVG aria-hidden=true、focusable=false；信息图有可访问名称和文本/数据替代，title/desc ID每实例唯一。

### 可读性与动态

[E] 功能辅助文字默认至少12px，移动输入16px；这是针对来源9–11px小字的改进，不是WCAG规定最低字号。字体、字重、真实屏幕与文字缩放一起验证。不要全局固定根字号阻止用户偏好。

减少动态时仍显示状态，去掉位移、角色循环和共享元素动画；颜色反馈可立即发生。不要让用户等插画播完才能操作。

### 验证的范围

浏览器自动检查能发现溢出、失焦、缺标签、部分对比问题，不能代替读屏和真机。交付说明应分别记录：自动检查、截图目检、键盘检查、读屏/真机未验证项。高对比模式下用真实边框/outline保留识别；不要只用box-shadow作焦点。[E]


## 12 · 反模式

反模式由来源演进归纳，不把所有现代UI形式一概禁止。S 编号见第 14 节「研究依据、差异与信息缺口」。

| 错误表现 | 为什么破坏语言/依据 | 推荐替代 |
|---|---|---|
| 米色背景＋通用无衬线粗标题＋三张发光卡 | 丢掉刊物排版、开放空间和情境笔触 [S01 S02] | 宋体层级、真实任务构图、一个相关场景 |
| 大面积装饰渐变、玻璃、霓虹蓝 | 与纸墨平面质感不一致；源规范明确收敛，旧水墨光晕还被禁用 [S01 S02] | 平涂纸层级、细线；真实热图渐变可作为数据编码 E |
| 全站纯黑或冷白底 | 色温丢失 [S01 S02] | 暖炭/暖纸；真实照片、代码语法、图表内容可保留必要色 |
| 每个区块都边框＋标题横线＋卡片阴影 | 重复边界让内容消失在线条间；后期原型专门删线 [S06 S07] | 先空白/基线，必要边界只留一次 |
| 一概禁止网格、浅底卡片、任何圆角 | 与原图不符：有开放三列、浅底重点区和2–4px角 [S04 S06 S08] | 禁的是浮卡墙和大圆角嵌套，保留有意义的分组 |
| 任何页面强行非对称 | 来源平级入口本就规则对称 [S04]；随机错位损害扫描 | 在功能网格内准确对齐，主次区可不对称 |
| 输入框、按钮、表格也画成歪线 | 将装饰层的不规则转移到可靠操作层 [S08 S09] | 精确控件＋旁侧手绘图；数据线保持真实尺度 |
| 用所有来源角色装满首页 | 来源插画总览是资产目录，工作页实际更克制 [S02 S07] | 一个与动作相关的场景，小图只在必要处呼应 |
| 每张图都笑脸＋三颗星 | 幽默退化为贴纸，没有任务关系 [S03 S04 S06] | 一个道具关系和一个微小意外；星星可以没有 |
| 所有插画必须是墨团或猫 | 把品牌形象等同设计语言；已有纯物件场景 [S04 S06] | 同笔触的新主题主体，不复制Logo |
| 让幽默代替错误/权限/进度 | 可用性受损；源规范保留真实状态 [S01 S08 S10] | 先清楚原因、影响和下一步，图形只陪衬 |
| 每页大英文手写口号、满屏旋转照片 | 旧拼贴表达不能覆盖后来的安静工作界面 [S07 S12] | 手写仅非必要短批注；照片只在策展情境少量组合 |
| 强制所有照片灰度 | 历史稿已有修订声明，用户内容应保真 [S12 S13] | 原色内容；品牌策展可有明确黑白处理 |
| 把9px/低对比浅灰当精致 | 原实现局限不是可复用优点 [S08 S10] | 有用小字≥12、对比实测；保留留白而不牺牲阅读 |
| 将所有蓝色都作为品牌按钮底 | 后期明确墨色主操作、蓝色关系标记 [S01 S02 S09] | 主按钮ink；蓝色链接/焦点/选中/图中点题 |
| 持续漂浮、鼠标追随所有角色 | 把局部猫动画扩成全局噪声 [S05 S15] | 默认静态，用户触发的短反馈，减弱动态可停 |
| 为统一风格扭曲图表或移除表格列 | 内容真实性不是装饰变量 [E] | 精确数据编码，图表周边使用同一纸墨排版 |

检查一个新页面时先指出具体偏离和其功能影响，再修改。不要仅以“太SaaS”“不够高级”作评审结论。


## 13 · 跨场景迁移与验证

两个场景都是本次[E]扩展设计，不是来源项目的页面。所有数据是明确标注的固定样例；没有调用API、上传材料、部署网站或实现生产服务。

### A：AI 材料整理工作台

完整源码见第 15 节内的 `AI 工作台 HTML` 完整代码块；共用样式、脚本和线稿均在本文代码章节。

- **首页/信息架构**：开场说明输入与整理任务，直接进入左右并置的输入/结果，下方是最近处理记录。没有文章流、个人空间或博客模块。
- **导航**：顶部“整理材料／处理记录”按任务与历史组织，当前示例是同页定位；真实应用可据对象数量决定是否独立路由。
- **卡片/表单**：输入是开放工作列，结果为轻纸面分组；单选方式、可选补充要求、一个主操作。不是三个功能卡加大Hero。
- **插画**：新机器人用细线扶齐数据片，墨色面板与纸色表情提供视觉锚点；没有复制原墨团商标。
- **空/加载/失败**：空状态清楚说明第一份材料尚未到来，辅助任务清单小图；加载静态骨架＋文案；失败保留输入并说明重试；结果样张明确不是实际AI分析。
- **响应式**：手机上下排列输入与结果，隐藏页首大图，保留结果区小场景，操作与辅助文字可换行。

### B：数据分析平台

完整源码见第 15 节内的 `数据分析 HTML` 完整代码块；它与工作台共用视觉 Token，但采用不同信息结构。

- **首页/信息架构**：从时间范围到指标带、每日趋势、来源完整性、同步记录；首要工作是观察和比较，故没有输入/生成的双工作台结构。
- **导航**：左侧窄目录定位四个分析部分；窄屏变行内导航，保留当前语义与可触区域。
- **卡片/表单**：指标放在连续账册带，不分别装悬浮卡片；日期表单紧凑，记录使用真table和局部滚动。新产品需要排序等高级能力时另行实现，不假装样例已有。
- **插画**：只在“缺第二数据来源”的解释区绘制数据种子接线；真实图表保留精确矩形、基线和2px/次一致比例。
- **空状态**：明确只能看到一个来源，不能伪造对照；说明按钮打开纸面dialog。搜索无结果是文本状态，不重复大插图。
- **响应式**：平板收侧栏；手机指标变键值行，趋势保留可读数值，来源说明移到下方，表格局部横滚，不删列假装适配。

### 共同DNA与不同结构

| 项目 | 相同的语言 | 有意不同的组织 |
|---|---|---|
| 字与色 | 同一纸/墨/蓝、宋体层级、可读小字 | AI解释任务，分析屏突出数字与单位 |
| 控件 | 墨色主按钮、精确边界、小圆角、蓝焦点 | AI文本输入＋单选；分析日期＋搜索＋dialog |
| 容器 | 无卡片阴影、留白/必要细线 | AI开放工作列＋结果纸面；分析指标带＋表格 |
| 插画 | 1.6/1.7线、圆头、局部墨块、新主题隐喻 | AI机器人整理片；分析种子等待接线 |
| 小屏 | 文字和热区不随图缩小 | AI先输入后结果；分析先范围/指标后比较 |

  const first = controls[0];
  const last = controls.at(-1);
  if (!first) { event.preventDefault(); return; }
  if (event.shiftKey && document.activeElement === first) { event.preventDefault(); last.focus(); }
