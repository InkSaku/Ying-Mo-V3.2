# 翻回这一页

开发环境可回放：<http://127.0.0.1:5173/dev/login-page-turn>。预览不执行登录，不读取成员内容，使用与正式流程相同的动画引擎。

正式登录认证成功后立即导航：目标为首页时，在 90ms 的挑书动作后，让右下角沿折线向左上翻起，总时长约 820ms；其他返回地址仅 160ms 淡出，路径、查询与片段继续保留。首页加载与翻页并行，不等待动画完成才请求内容。失败不翻页；普通导航和刷新不重播。

## 实现

- `frontend/src/lib/pageTurnGeometry.js`：使用 x+y=fold 裁切旧纸页，反射右下角得到纸背，不对整页正文旋转或缩放。
- `frontend/src/lib/loginPageTurn.js`：准备脱敏、禁用交互的 DOM 副本，管理跨路由动画、超时回收、焦点与中断。副本中的输入控件被替换为固定示意内容，不保留凭证。
- `frontend/src/styles/login-page-turn.css`：浅／深纸背、细折痕及轻薄投影。
- 续火花助手保留角落入口，取消居中迁移和自动循环，移除旧的独立挥手问候。
- `frontend/src/pages/LoginTurnPreview.jsx` 仅在开发模式注册，生产构建会裁去该预览。

## 验证范围

几何回归覆盖手机、平板、桌面和超宽比例的面积守恒、折线连续及结束时完全离屏。浏览器回归覆盖真实认证、错误、明文密码脱敏、原地址返回、重复回放、浅／深主题、390/1440px、缩放／返回／动态偏好变化清理、减少动态及刷新不重播。手机软键盘和读屏尚未做真机实测。
