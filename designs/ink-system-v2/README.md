# 映墨 · 墨团书房 UI

先设计 SVG 场景，在 `index.html` 的线稿样张中确认构图，再接入实际页面。

## 视觉规则

- 纸色 `#f8f7f3`，墨色 `#242520`，少量蓝色 `#334b76`。
- 深色主题使用夜纸 `#20231f`、浅墨 `#e5e5dc`、蓝色 `#9cb4db`。
- 不规则墨团轮廓，圆头线条，少量手绘星光。全部插画为 SVG。
- 大插画用于入口；中等插画用于页头；小插画用于页边和空状态。
- 内容、头像、封面仍由真实记录提供。插画不承载按钮功能。
- 工具和表单采用细边框、2px 圆角；主按钮以墨色强调。
- 手机减少装饰，确保标题、表单与操作仍清楚可见。

## 实现入口

- `frontend/src/assets/ink/`：12 个原创场景。
- `InkSketch`：统一主题、尺寸、装饰语义。
- `InkPageSketch` / `inkScenes`：页面任务与插画对应。
- `InkBrandMark` / `public/ink-mark.svg`：导航和浏览器页签标识。
- `ink-system.css`：全站样式；`ink-sketches.css`：插画基础规则。
- PWA / iOS 图标使用同一墨团标识，并保留 maskable 安全区。

浏览器检查覆盖浅色 / 深色与 1440、768、390、320px，另有原有业务交互回归。

## 验证结果

- lint、136 项单元测试、生产构建、包体校验通过。
- 原有浏览器用例：20 项在全套运行中通过；首页 4 项与随记 1 项在独立测试环境中通过。
- 新增全站视觉与布局用例：3 项通过，覆盖公开入口、个人与写作页、全部后台入口。
- 全套浏览器测试共享后端种子数据，首页与随记的固定记录数量断言会受前序测试创建的内容影响，因此这两组另行隔离验证。
- 实际页面截图保存在 `screenshots/`；`pages.html` 为页面预览，`index.html` 为线稿总览。
