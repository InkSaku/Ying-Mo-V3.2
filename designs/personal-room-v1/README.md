# 我的六处小书房

根据用户提供的第三轮线稿设计板，把 `/me` 的六个数字入口改成六幅线稿组成的入口页。

先完成 `index.html` 的独立设计板，随后把同一份 SVG 嵌入 `MePage`。五幅新作加一幅已确认的信箱小鸟，均为原生 SVG，使用系统纸色、墨色与蓝色变量。

| 入口 | 线稿 | 标题 | 路由 |
| --- | --- | --- | --- |
| 内容 | 书页与小叶子 | 留在纸上的日常 | `/me/posts` |
| 草稿 | 歇一会儿的铅笔与茶杯 | 还没写完，也很好 | `/me/posts?status=draft` |
| 合集（Collection） | 不太齐整的小书架 | 把故事，收进同一册 | `/me/collections` |
| 收藏 | 猫与书签 | 喜欢的，留一枚书签 | `/me/favorites` |
| 评论 | 两杯茶与对话 | 说过的话，都有回声 | `/me/comments` |
| 未读通知 | 小鸟送大信封 | 回信，在这里落脚 | `/me/notifications` |

布局在桌面保持两行三列，平板两列、手机一列。保留大量留白与横向细线，入口数量放在右上角，采用原有账户统计。整格为原生链接，支持键盘导航，焦点有可见轮廓。

通知数量为零时，短文案会切换为“信箱先歇一会儿，回信到了会放在这里。”

- `index.html`：线稿与排版设计板，数量为示例。
- `preview-light.png` / `preview-dark.png`：设计板预览。
- `pages.html`：嵌入系统后的实际界面预览。
- `screenshots/`：桌面与手机截图，测试环境账号，数量为验收样例。

长截图只在截取时临时隐藏固定导航，所有点击和键盘检查保留正常界面。

验证：静态检查、148 项前端单元测试、生产构建及体积预算通过；4 项浏览器场景通过，包含个人空间六入口、头像状态和既有桌面/手机布局。覆盖五种宽度、两种主题、全部入口跳转、草稿筛选参数、键盘 Enter、大数量及零未读状态。
