# 映墨 · 发布与主题设计提案 v1

本轮仅设计：所有文件都在设计目录中，没有修改网站源代码，没有接入 API。

## 三幅原创线稿

1. **给这一页找个家**：墨团把稿纸收进书册，蓝色书签留住入口。用于合集选择。
2. **把词挂起来**：墨团够着一张标签，像晾起一小片日常。用于标签搜索与选择。
3. **顺着线，找到彼此**：词与书页由细线连接，绕一圈的小路留下幽默。用于主题索引与标签分区。

## 页面与交互

- `sketches.html` / `sketches.png`：线稿独立样张。
- `index.html`：独立交互设计预览，顶部切换发布确认、主题索引、标签分区。
- `publish-desktop.png` / `publish-dark.png` / `publish-mobile.png`：发布窗口的桌面、深色与手机视图。
- `tag-match.png`：重复标签名称的即时匹配状态。
- `tag-index-desktop.png`：按可见引用数排列的前十主题。
- `tag-detail-desktop.png`：对应主题下的记录分区。

发布窗口中的合集以小册页呈现，支持不加入合集，并明确显示阅读范围。

标签主体用于选择，单独的 ↗ 用于查看主题分区；每个标签显示引用数。搜索能匹配已有标签或展示创建入口，已选项可移除。返回写作后再次打开窗口会保留选择。

原型中的合集、引用数和文章均为演示数据。确认发布只显示演示状态，不会创建或发布实际记录。类型筛选是视觉占位，未实现真实数据筛选。
