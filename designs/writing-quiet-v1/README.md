# 安静写一页

写作页不再把编辑、归属、发布、图片和装饰同时展开。先完成独立排版设计板，再把布局嵌入真实写作页。

## 界面

- 默认居中单栏，正文宽度最多 780px。
- 文稿信息在所有屏幕尺寸下按需打开，仍可设置自动网址、分类、合集、可见性、标签和封面。
- 标题和正文周围没有装饰边框、底线或侧栏分隔线。
- 取消画布上方的书桌插图、英文手写大字和重复标题。
- 小猫留在正文下方，移除贯穿画布的横线。
- 常用排版与图片入口保留；编号、脚注、公式、代码和表格收进“更多”。沉浸写作功能保留。
- 段落样式与撤销/重做在当前文字段获得焦点时出现，保留占位避免输入时跳动。
- 可视编辑、Markdown 源码、正文预览、图片插入/设置/排序与自动保存继续使用原有编辑逻辑。
- 发布时仍弹出合集、标签与可见性确认。
- 手机使用简洁的顶部操作区，正文下方不叠放全站导航。

## 交互完善

- 文稿信息支持 Escape、Tab 焦点循环、关闭后回到触发按钮以及滚动锁定。
- 设置封面会关闭文稿信息，并将焦点与滚动定位到图片区。
- 更多菜单在窄屏仍完整位于视口内；选择格式或移开焦点后关闭。
- 默认画布与图片编辑块的外框已移除。用户正文的表格、引用等格式仍保留。
