# 纸墨换色

手动换色时，从触发按钮中心晕开一次 560ms 的墨迹：浅转深为现有墨黑，深转浅为暖纸白；沿不规则轮廓显露真实的新主题。照片不做反色，文字、输入节点和页面位置保留。

使用浏览器 View Transitions 捕获同一页面的前后主题，768 点多尺度轮廓只向外生长，以 Web Animations 播放遮罩，不增加依赖或逐帧重建页面。主题换色临时关闭文章独立转场名，结束后恢复。连续操作、滚动、缩放、导航和偏好变化及时清理；动画失败仍应用所选主题。初次打开、系统自动换色、实际颜色不变及减少动态模式直接应用主题；不支持该 API 的浏览器保留即时换色。

开发预览：<http://localhost:5173/dev/theme-ink>。主按钮可直接来回切换，右上角保留“跟随系统／浅色／深色”。下方可输入临时文字验证保留情况。页面仅在开发环境提供；照片复用项目已有资源，示意文字不保存。

已通过前端完整检查（165 项单元测试、lint、构建、包体预算），以及 7 项主题、导航栏和文章转场端到端测试。覆盖 1440px/390px 两方向截图、键盘起点、连续选择、滚动/缩放/退出/偏好变化、系统主题、无 API 降级、输入节点保留、照片无反色及文章转场恢复。未做实体手机、读屏器或老版本浏览器真机验证。
