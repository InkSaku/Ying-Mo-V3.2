# 翻开封面

已有登录状态的访客从 `/` 打开网站，确认会话有效后，欢迎页右下角沿对角折线翻走，真实首页同时进入。总时长 550ms，没有额外角色表演；与登录成功的 820ms 翻页共用纸背、折线和清理逻辑。

- 确认会话期间保留完整欢迎页，失败留在欢迎页。
- 离开欢迎页后不自动拉回；导航替换历史条目，站内链接与刷新首页不重复播放。
- 慢首页数据保留正常加载和错误状态，不延长覆盖；减少动态时直接进入。
- 开发预览：`http://localhost:5173/dev/login-page-turn?from=welcome`，可重复播放，也可切换登录翻页作比较。预览首页为明确标注的示意内容。

`screenshots/` 保存 1440px 和 390px、浅/深主题的折页中段。已通过前端完整检查（163 项单元测试、lint、构建和包体预算）与 16 项登录/转场端到端测试，覆盖真实会话恢复、匿名、离开取消、慢/失败数据、返回历史、减少动态与两主题预览。未进行实体手机或读屏器测试。
