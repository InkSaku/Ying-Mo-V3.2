# 映墨 · 书房里的小事（第三轮 UI 升级）

先在独立设计板完成五幅 SVG，再复用同一份素材嵌入系统。轻微偏斜的轮廓、纸色背景和蓝色小提示延续现有线稿语言，物件里加一点轻松的巧思。

| 线稿 | 页面 | 界面调整 |
| --- | --- | --- |
| 装满记录的行李 | `/me/data` | 图与导出清单分栏；小屏改为轻量图注；明确四类打包内容 |
| 送信的小鸟 | `/me/notifications` | 通知总数、本页未读数、安静的信件列表和专属空状态 |
| 钥匙与打盹的猫 | `/me/sessions` | 设备列表改为记录册；当前设备优先；日期与结束会话按钮有清晰层次 |
| 口袋里的书房 | `/me/settings` 的安装区域 | 小幅插图与安装说明组合；保留浏览器指导和安装反馈 |
| 可以回头的书页 | `/me/posts/:id/revisions` | 未选版本时的引导线稿；选择后在页头保留小图 |

收藏和搜索无结果状态也使用与功能对应的既有线稿。

## 预览

- `index.html`：独立线稿设计板，支持换成深色纸。
- `pages.html`：实际实现的页面内容截图，浅色桌面与深色手机各一组。
- `preview-light.png` / `preview-dark.png`：设计板截图。
- `screenshots/`：实际页面截图；通知、设备和版本历史使用浏览器验收样例，导出与设置使用测试环境真实接口。

长截图只在截取时隐藏固定导航，以免把导航叠在页面正文中；交互验收保留真实导航。截图对应 1440px 桌面和 390px 手机，布局检查另外覆盖 768px、320px。

## 验证

- 前端静态检查、148 项单元测试、生产构建与体积预算通过。
- 8 项浏览器场景通过（本轮 3 项、既有全站线稿 3 项、个人空间布局 2 项）。
- 本轮交互覆盖真实 ZIP 下载及失败后重试、安装提示与已安装状态、通知标记已读、结束设备会话的取消/确认，以及版本选择和恢复弹窗取消。
- 移动端验证浅色/深色下无横向溢出。
