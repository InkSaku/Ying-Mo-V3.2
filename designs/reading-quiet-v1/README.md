## 实现与小猫

用户后续要求“灵魂小猫原样保留”，因此实现中继续把原有小猫放在阅读进度区，保留原图、尺寸、行走方向、动画与进度联动。其绘图文件 `ArchiveCatDrawing.jsx`、动画样式 `archive-cat.css`、公共组件 `ArticleSketches.jsx` 的 SHA-256 与本轮修改前一致；原有阅读猫轨道样式也保留。

标题、摘要、元信息、封面和正文合并到同一阅读列，调宽时一起重排。仅在首个正文 H1 与文章标题一致时省去重复显示，保留锚点；数据库与 Markdown 原文不改。

主要章节与子标题按需展开，深层链接可以正常定位。字号支持 16–24px 与记忆，纸色沿用全站主题。顶部收藏和文末收藏共用一个状态及原有请求逻辑。

实际页面截图使用测试文章。长截图只在截取时隐藏固定导航，以避免导航叠在正文中；交互检查保留真实界面。
