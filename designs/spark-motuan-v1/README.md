# 墨团 × 火花 · 续火花页面原型 v1

为 `/tools/spark` 设计的墨团线稿与桌面 UI 概念图。沿用现有墨团的不规则墨色轮廓、白色笑脸、细线手脚；火花、信封与日历使用少量靛蓝线条。保持映墨纸色、细边框和小圆角。

## 三枚线稿

| 场景 | 设计 | 原始 SVG |
| --- | --- | --- |
| 页头 | 墨团在纸碟里捧住一簇火花；把每日问候理解为一份轻轻托住的微光。 | [捧住今天的火花](hold-the-spark.svg) |
| 消息区 | 一封带火花的信沿蓝色细线落进墨团手里。 | [接住一封问候](catch-a-greeting.svg) |
| 计划状态 | 墨团把一簇火花留在日历的一天。 | [给每天续一点光](keep-the-day-glowing.svg) |

SVG 使用 320×220 viewBox、1.6–1.7px 圆头线条。默认纸色 `#f8f7f3`、墨色 `#242520`、靛蓝 `#334b76`，通过 `--ink`、`--page`、`--brand-link` 变量可适配主题。

## UI 构思

- 页头只保留一句主题与一个中等尺寸场景，控制装饰比例。
- 已连接账号收成横向信息栏，管理与备用方式保持次要层级。
- 好友选择和每日问候并列，搜索、筛选、勾选和预览都能直接看到。
- 检查与开启单独成行，用准备状态解释下一步；每日计划、模拟检查、立即发送分开。
- 执行记录以紧凑列表呈现，保留筛选、刷新和展开入口。

## 生成与复用

线稿来自现有项目 SVG 角色的原生延展；`lineart-board.png` 由本地 Playwright 渲染。UI 原型使用内置 imagegen，根据既有页面截图和线稿总览生成。[完整生成提示词](prompt-ui.md)保存在本目录。

UI 图使用示例账号与示例执行记录，是视觉概念稿。生成图中的小字和控件状态在实际实现时以代码与产品逻辑为准。SVG 是可直接复用的原始资产。

重新生成线稿预览：在项目根目录运行 `node designs/spark-motuan-v1/render-board.mjs`。
