# 纸上动作 · 第一批交互

体验入口：`http://localhost:5173/dev/paper-motion`，无需登录，使用明确标注的示例内容；生产构建不包含预览页。

实际接入：

- 合集目录：点击封面或标题，封面轻抬、移到详情封面位置并沿左侧书脊掀开。导航立即开始，真实加载与错误保留。
- 全站媒体灯箱：照片从原缩略图展开；关闭、Esc、向下拖动或浏览器返回时，回到当前照片可见的缩略图。等比缩放与裁切保留影像比例，焦点立即还给打开入口。
- 首页随记：展开与收起便笺，保留本地文字和焦点；仅在真实发布成功后收回，并短暂强调新加入时间轴的记录。

使用原生 Web Animations API，没有新增运行时依赖。减少动态、尺寸变化、连续操作、错误与超时均有退化/清理路径。截图覆盖 1440/390px、浅色/深色；布局另外检查 768/320px。截图中的开册与照片中间帧通过测试暂停实际动画取得。
