# 安静一点的漫游

针对漫游页面分隔线过多、编号重复、空栏目占位与图文层次混乱的问题，先完成独立线稿及排版设计板，再嵌入真实页面。

## 设计

- 开场只留“地图绕个弯，走到一杯茶”的一幅线稿。
- 标题、介绍、换批按钮组成紧凑的页首。
- 开场文章用浅纸色突出，途中拾到的随记放在旁边。
- 后续文章与随记使用统一网格，标题在上、影像在下；不画行分隔线。
- 标签以浅纸色块分组，合集以内容本身作入口。
- 往年今日使用安静的纸色背景，新朋友以小头像和简介呈现。
- 移除反复出现的栏目编号、条目编号、英文手写大字、装饰箭头，以及各级边框。
- 没有内容的栏目不渲染；全部为空时提供一个有用的空状态。

随机 seed、URL 分享、浏览历史、阅读权限和现有入口逻辑保留。

## 文件

- `index.html`、`design-preview.png`：先行设计板。
- `paper-detour.svg`：本轮原生 SVG 线稿。
- `pages.html`：实际界面预览。
- `screenshots/`：有/无封面的桌面、手机截图。内容及封面为验收样例。

长截图仅在截取时隐藏固定导航，操作检查保留正常界面。

## 验证

前端静态检查、148 项单元测试、生产构建和体积预算通过。4 项浏览器场景覆盖：纯文字内容、全部为空、图文混排、仅部分来源有数据；另覆盖五种宽度、浅色/深色主题、开场无重叠、换批时保留可读内容、返回上一批恢复 URL 与内容。
