## 统一设计语言

背景为接近白色的暖白，正文为近黑色；中文标题与正文采用轻盈宋体方向，操作文字采用清楚的小型 UI 字体。照片采用黑白或极低饱和的生活影像，墨蓝只用于少量手写短句、箭头与下划线。主要内容直接排列在页面上，以留白、细线和对齐建立层级。

拼贴集中用于首页与合集；列表、阅读、写作按实际使用任务组织。矩形操作按钮保留清楚边界，图片保持直角。

本轮提出统一导航“首页 / 漫游 / 合集 / 查找”，写作、通知和个人入口位于右侧。“查找”是现有文章、随记、分类、标签、归档与搜索的入口分组提案，不代表后端新增资源。

## 对现有系统的适配

- 首页保留快速随记的图片、发布范围及发布动作，朋友近况容纳 Article 和 Note。
- 文章列表把大段介绍压缩成短刊首；分类、标签、作者与合集筛选仍可使用。
- 文章阅读保留作者、时间、可见范围、目录、收藏与评论；不同表情可通过紧凑入口展开。
- 合集详情保留创建者、共同成员、时间轴、内容与媒体视图，以及通知偏好；“管理合集”展示的是创建者视角。
- 写作页区分“草稿仅自己可见”与“发布后的范围”，保留网址、分类、标签、封面、预览及媒体排版。
- 将来实现黑白展示效果时，应作为展示层的视觉处理，保留用户原始照片及原图下载能力。

## 下一轮细化

本轮覆盖桌面主状态。后续页面实施时需进一步确定移动端折叠、筛选展开、空状态、图片失败、保存冲突与撤权状态；这些未在本轮五张静态图中逐一展开。

PNG 为视觉方向稿，实际尺寸见文件属性；生成时使用了桌面全页构图提示，输出尺寸由 ImageGen 决定。具体字号、间距和断点可在 HTML/CSS 原型阶段按设计文档精确落地。
