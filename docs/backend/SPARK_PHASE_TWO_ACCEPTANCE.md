# 续火花第二阶段验收记录

基线为 `4c518ac`，开发分支 `codex/spark-phase-two`。本阶段将网页扫码连接、候选账号确认、自动联系人同步和四步设置接入现有串行 worker；备用脚本上传继续保留。

## 已实现

| 范围 | 实现与边界 |
| --- | --- |
| 网页扫码 | 读取官方 `/chat` 登录页成功签发的 `/passport/web/get_qrcode/` PNG，等待实际二维码节点显示；不截取包含扫码说明动画的外层容器，不解决或绕过安全挑战 |
| 鉴权图片 | JWT 请求头获取 PNG Blob，禁止缓存，不使用 token 查询参数或公开媒体目录 |
| 临时会话 | 加密二维码及候选登录态；账号代次与凭证版本阻止旧结果覆盖；跨成员返回 404 且不修改原会话 |
| 刷新与取消 | 返回最新会话摘要；重复普通请求恢复现有会话，强制重连使旧会话失效；取消清理密文并终止浏览器进程组 |
| 生命周期 | 排队 30 分钟、实际扫码 180 秒、待确认 5 分钟；待确认时浏览器已经关闭；重启中断执行中的会话 |
| 绑定与同步 | 用户确认才写入正式凭证，绑定和自动同步入队同一事务；重复确认不重复绑定或同步 |
| 同号与换号 | 带来源的身份摘要比较；缺少可靠身份按新账号处理；同号保留好友，换号清空好友；两者均暂停每日发送 |
| 四步设置 | 连接、选择好友、保存问候、检查并开启；前端保留未保存编辑，手动添加好友前要求保存选择 |
| 后端启用条件 | 当前凭证、所选全部好友与消息/通道一致的完整成功模拟，并且计划已经保存；失败的新检查清除旧检查结果 |
| 兼容已有计划 | 迁移保留第一阶段已启用计划；重新绑定、改变好友或消息/通道设置后进入新检查流程 |
| 重连核对 | 同步保留旧联系人供核对，标记本次未找到的联系人，不能把未找到直接视为解除好友关系；未确认对象跳过发送 |
| 调度 | 到期自动发送优先；扫码完成后给其他就绪任务一次执行机会，手动任务不会持续压住扫码 |
| 输入清理 | 使用 `ControlOrMeta+A`，发送前校验输入内容完全一致，防止原有草稿混入 |

平台是否提供可靠“已扫码待手机确认”信号尚未验收，因此保持“请扫码并在手机确认”状态，不推断已扫码。账号昵称通过自身资料响应读取；读取不到时显示通用账号名称，不能凭昵称判断同号。

超时会话无法确认。密文在后台巡检或接口读取时清理；后台停止期间不会承诺定时物理删除，数据库备份和历史日志也不是“阅后即焚”。

## 真实平台验证与剩余验收

已完成的实际平台探测：

- 首页首次访问出现“验证码中间页”；正常聊天页入口可以渲染登录弹窗和真实二维码。
- 独立探测能够取得真实二维码 PNG。
- 当前本机网站前端代理 → 鉴权扫码会话接口 → 单 worker → 真实 Chromium → 加密二维码 → 鉴权 PNG 读取通过；随后取消，确认二维码密文清理及连接终态。此验证没有扫码登录、没有绑定账号、没有读取好友、没有发送消息。

手机确认后的真实浏览器曾取得 `sessionid` 和账号标识，但官方页面附带的无名访客 Cookie 被严格导入校验拒绝，候选登录态未保存。已在自动浏览器导出时过滤无名 Cookie，文件导入仍保持严格校验，并加入回归测试。还修正了外层扫码说明动画被当成二维码图片的问题；当前只发布官方接口成功签发的 PNG。另有临时码因未及时扫描而超时。

本次网页扫码在手机确认后真实返回 `check_qrconnect` 的 `error_code=2046`，且没有登录凭证。可见的官方浏览器进一步显示短信或身份验证要求，已由用户本人完成；备用脚本随后保存有效登录态，过滤无名访客 Cookie 后通过严格校验。登录态已加密进入候选账号流程，用户在网页点击“确认连接此账号”完成绑定。此结果证明备用验证路径通过，不能宣称纯网页扫码已完成这个账号的额外验证。

真实 worker 在全新 Chromium 中恢复该登录态并读取 31 位联系人。首次同步遇到父进程仍持有旧事务快照，将子进程已经完成的任务覆盖为中断；已修正为丢弃旧事务并锁定当前任务行再判断。回归测试修复前能复现 `succeeded` 被覆盖为 `failed`，修复后通过。重启本地 worker 后再次真实同步，任务为 `succeeded`，结果为“同步完成”，数量 31。每日发送保持关闭，没有发送消息。

真实好友模拟检查，以及一个由用户明确选择的测试好友发送，仍需通过网页入口验收。不能以离线模拟结果代替。

没有访问生产服务器，Linux 网络下登录表现、服务重启、实际峰值内存和平台验证行为仍需部署后检查。`MemoryMax=1800M` 是进程组内存限制，不能证明没有 OOM 或任务失败。

普通用户本地使用：启动网站后端、前端及 `scripts/run_local_spark.py`，打开 `/tools/spark`，直接点击扫码连接。无需下载脚本或处理 JSON。部署与密钥说明见主 README。
