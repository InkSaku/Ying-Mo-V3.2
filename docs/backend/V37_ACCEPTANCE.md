# Ying-Mo V3.7 轻量互动验收

更新时间：2026-08-24

本文是 V3.7 轻量互动专项的历史验收记录，不代表当前工作区已重新通过验收。

| 验收域 | 完成定义 | 状态 |
|---|---|---|
| 固定回应 | Post 与 active 评论固定六种语义回应；每人每目标最多一种；设定、切换、重复请求和清除幂等 | 自动化通过 |
| Like 兼容迁移 | `content_likes` 数据转换为 `post_reactions.kind=heart`；支持 MySQL DDL 中断续跑与旧表缺失恢复；旧 Like API 继续返回兼容状态，不生成通知 | 自动化与真实 MySQL 通过 |
| 评论乐观更新 | UUID 请求标识按作者唯一；前端先插入临时节点，成功替换、失败回滚并恢复正文/回复/提及草稿 | 自动化通过 |
| 回复与引用 | 任意回复压平到一级根评论；保留直接回复目标并展示可见引用摘要，不产生递归楼层 | 自动化通过 |
| 结构化提及 | 候选只包含目标 Post 当前 active 可读成员；提交再次校验，重复、自提及和失权目标被拒绝 | 自动化通过 |
| 通知偏好 | `all`、`important`、`muted` 对新 Post、评论、回复、提及和直接治理通知按产品分级 | 自动化通过 |
| 摘要与深链 | 通知展示纯文本评论摘要；目标携带评论查询参数和锚点；上下文接口计算根评论所在页 | 自动化通过 |
| ACL 撤销 | 成员移除后 Post、评论、回应、提及候选和上下文接口统一 404；历史通知移除目标、摘要和对象 ID | 自动化通过 |
| 轻量同步 | 继续使用未读计数、约 60 秒轮询、焦点/页面恢复和会话事件；没有聊天、在线状态或长连接 | 自动化通过 |

浏览器视觉验收和最终全量门禁结果记录在 `VALIDATION.md`；未实际执行的项目不得改写为通过。
