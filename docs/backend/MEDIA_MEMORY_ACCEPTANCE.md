# 媒体记忆与沉浸灯箱验收

更新时间：2026-08-24

## 已交付范围

- 全局灯箱覆盖 Post 正文/封面、Collection 影像墙、年度回顾、我的媒体和往年今日所复用的 Post 卡片入口。
- 图片与 Live Photo 统一为逻辑媒体；Live Photo 图片和视频只计一个条目，动态失败时保留静态照片。
- Collection 相册支持年份、成员、图片/Live Photo 筛选、服务端分页、原 Post 跳转及当前筛选序列浏览。
- `?media=<public_id>` 支持刷新恢复并保留其他 Query；无权、删除和失去成员关系统一展示 404 语义。
- 灯箱支持左右按钮、方向键、Esc、背景关闭、移动滑动、双击/双指缩放、焦点陷阱和关闭后焦点恢复。
- 上传生成无 EXIF 的 WebP 展示图和缩略图；原文件保持私有且只有所有者可以下载。
- 当前媒体按需读取、相邻静态图短时预加载；退出、会话失效或切换账号释放全部 Blob URL。

## 权限验收矩阵

| 场景 | 预期 |
| --- | --- |
| Collection 当前成员读取相册、解析媒体、读取展示文件 | 200 |
| 已知媒体 UUID 的非成员读取 | 404，不返回作者、Post 或 Collection 信息 |
| 成员被移除后再次读取相册、解析地址或展示文件 | 全部 404 |
| 普通成员请求他人原文件 | 404 |
| 所有者请求本人原文件 | 200，保留原 MIME 与文件内容 |
| 退出、Token 失效或切换账号 | 清空灯箱并释放受保护 Blob URL |
