## 第二十二阶段：邮箱可信与账号恢复 DoD

| 验收域 | 完成定义 | 状态 |
| --- | --- | --- |
| 产品兼容 | 邀请码注册成功即为正常成员；未验证邮箱不阻断登录、阅读、写作和成员能力，验证只建立可信恢复通道 | 通过 |
| 邮箱验证 | 注册创建验证令牌并尝试投递；登录成员可重发；确认成功写入 `email_verified_at`，同用途旧令牌失效 | 通过 |
| 密码恢复 | 仅 active 且邮箱已验证的账号会收到重置邮件；未知、未验证、受限、冷却路径与有效路径统一返回 202 | 通过 |
| 令牌安全 | 原始令牌只在 URL fragment 和邮件中出现；数据库只保存 HMAC 摘要，并校验用途、邮箱快照、过期、撤销和单次消费；Query 令牌主动清除，页面与 Shell 使用 `no-referrer` | 通过 |
| 密码与会话 | 新密码沿用 8–128 字符策略；重置成功后消费令牌、撤销其他重置令牌和全部 Refresh Session、清除 Refresh Cookie，并通知其他标签页立即清理本地会话 | 通过 |
| 失败边界 | 邮件发送在账户事务提交后执行；投递失败不回滚注册，失败令牌被撤销，用户可以立即重新申请 | 通过 |
| 日志与邮件适配 | Console 和异常日志不记录完整邮箱、完整链接或原始令牌；SMTP adapter 固定发件人并覆盖 timeout、STARTTLS 和认证 | 通过（仓库内） |
| 前端闭环 | `/forgot-password`、`/verify-email`、`/reset-password` 均为公开路由；登录、注册、设置页有真实入口和状态反馈 | 通过（自动化与构建） |
