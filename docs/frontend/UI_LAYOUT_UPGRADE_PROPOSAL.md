# 映墨 UI 与布局升级方案 · 审查稿 v1

状态：设计提案，待审查。日期：2026-09-07。

本轮仅形成方案，未修改产品页面、现有设计规范或业务逻辑。依据为项目内 DESIGN.md、主要页面与组件源码，以及用户提供的 design.md、index(5).html、效果图。当前页面尚未做浏览器逐页实测，因此现状问题属于结构审查判断，尺寸为下一轮原型的起始值，不是已经验证的最终数值。

## 1. 设计方向

保留映墨的暖纸色、中文衬线字体、墨蓝与轻量控件；吸收参考页的主次关系、稳定对齐、开放排版、疏密节奏与局部影像构图。

目标观感：一处持续更新的朋友记录空间，文字清楚，照片有位置，阅读有节奏，使用起来轻松。

本次升级的主要变化应该发生在三个地方：内容更早出现；相同性质的信息位置更稳定；不同用途的页面拥有合适的密度与构图。

## 2. 两套设计如何取舍

| 维度 | 保留现有体系 | 从参考页吸收 | 最终决定 |
| --- | --- | --- | --- |
| 底色 | 暖纸色 #f5f4ed、浅象牙色 #faf9f5 | 大面积干净背景 | 保留现有颜色，不切换暖白 |
| 文字 | 现有中文衬线与等宽字体 | 用字号、位置、空白建立层级 | 不新增通用 UI 字体，不把英文大标题尺寸直接套给中文 |
| 强调色 | 墨蓝 #1B365D | 少量、集中使用 | 保留墨蓝；不加入第二套手绘颜色 |
| 容器 | 现有表单、按钮、弹层的克制圆角 | 阅读内容直接铺陈 | 内容列表减少外框，操作区域保留必要边界 |
| 图片 | 用户照片及原有媒体能力 | 主次、裁切与图文组合 | 内容照片保留原色，拼贴仅用于适合的封面场景 |
| 排版 | 中文阅读基础与日期索引 | 非对称分栏、横向目录、疏密变化 | 建立少量可复用的页面模板 |
| 装饰 | 纸张与墨色已构成识别度 | 克制的个人感 | 第一轮不增加手写字体；回顾页可试一处有意义的短注 |
| 动效 | 现有轻量交互 | 小幅、短时反馈 | 不新增滚动编舞；列表正文即时可读 |

文档关系：现有 DESIGN.md 继续定义品牌与基础控件。方案通过后，另建 LAYOUT.md 规定布局。涉及阅读字号、行高、卡片使用等已有规则的变化，应明确修改对应条款，避免两份文件互相矛盾。附件中的实现指令不直接成为项目命令。

## 3. 当前结构中值得优先解决的事

### 3.1 导航缺少分组

AppShell 当前同时陈列首页、漫游、文章、随记、合集、分类、标签、归档、搜索，右侧还有写作、通知、用户、主题、退出及管理员入口。入口完整，但同层级数量偏多；实际拥挤程度须在不同宽度与长昵称下验证。

### 3.2 首页开场层级较多

HomePage 包含介绍、延伸入口、输入区和时间流标题；HomeFeed 内又包含“刚刚发生”标题、主稿与辅助内容。建议合并重复开场，把第一条内容前的空间交给真正需要的写作入口。

### 3.3 编辑风格已有基础，但各页各自发明版式

文章列表已有主篇、辅助篇目和目录，随记已有年份分组，合集已有书架，归档已有卷册索引。下一步应统一正文起始线、标题等级与模块间距，减少重复小标题、英文眉题和解释文字。

### 3.4 时间流与精选的含义需要区分

HomeFeed 当前从前四条里优先选择文章作为主稿，可能改变用户感知到的时间顺序。提案建议首页按已有接口顺序展示；主次精选放在漫游、文章展示区和已有精选合集内。此项属于明确的展示行为变更，应在审查中单独确认方向。

### 3.5 部分文案在解释实现

例如“稳定抽取”“不形成推荐画像”等更适合帮助说明。页面优先说明用户能做什么。涉及谁能看到内容、发布范围、保存失败等会影响判断的信息继续明确展示。

## 4. 全站布局与 UI 规则

### 4.1 三种宽度、三种密度

第一轮沿用现有 1120px 页面宽度基准，核实当前盒模型后统一“最大外壳宽度”和“实际内容宽度”的定义，避免重复扣除内边距。

| 场景 | 建议布局起点 | 密度 |
| --- | --- | --- |
| 浏览、展示 | 外壳最大 1120px，内容用满可用宽度 | 中等；展示页局部舒展 |
| 长文阅读 | 正文最大约 680–720px，目录约 160–180px，间隔 40–48px | 段落舒展，辅助信息紧凑 |
| 表单、设置 | 简单表单最大约 560–640px；复杂编辑器沿用独立工作区 | 紧凑、有明确分组 |

页面边距起点：手机 20px，平板 32px，桌面 40–48px；最终依据可用空间调整。外壳不会因为加大留白而挤压中文标题。

双栏只在两边都能维持最小可读宽度时使用。默认考虑约 1040px 以上采用正文与边栏布局；平板与手机按阅读顺序上下排列。1440、1280、1024、768、390、320px 均需验证。

### 4.2 字号与行高

| 角色 | 桌面起点 | 手机起点 | 使用方式 |
| --- | --- | --- | --- |
| 展示标题 | 48–64px | 34–40px | 公开入口、个人介绍、年度回顾 |
| 日常页面标题 | 32–40px | 28–32px | 首页、文章、合集、归档 |
| 章节标题 | 24–28px | 22–24px | 同级模块统一 |
| 文章列表标题 | 22–26px | 20–22px | 让标题先于标签、统计被看到 |
| 随记文字 | 16–18px | 16–17px | 接近真实阅读文字 |
| 文章正文 | 18px | 17–18px | 原型比较 1.7 与 1.8 行高 |
| 元信息与控件 | 13–14px | 13–14px | 必要信息避免过小过淡 |

标题采用现有字体的 500 字重，正文 400。不用增多粗体解决层级。长中文标题自然换行，详情页完整展示；列表可对摘要做两行截断，普通标题优先完整显示，不设固定高度。

长文行高是对原 DESIGN.md 中 1.55 上限的拟议例外，须以真实文章比较后定稿，不把长文规则施加到表格与操作列表。

### 4.3 间距与对齐

- 文字与元信息内部：8 / 12 / 16px。
- 列表行之间：24 / 32px，按内容长度自然增长。
- 标题至内容：24 / 32px。
- 日常页面章节之间：48 / 64px。
- 展示页面的重点章节之间：80 / 96px。
- 每个列表有一条稳定的标题与正文起始线；日期栏、缩略图、操作不随条目随机漂移。
- 首页与查找页使用紧凑页头，不设置接近满屏的固定 Hero 高度。

### 4.4 容器、按钮与状态

内容本身主要用留白与分隔线组织。输入、筛选、通知设置、弹层保留浅表面与边界；不进行全站“去卡片”替换。

主按钮继续使用墨蓝与现有约 8px 圆角。浏览入口使用文字链接，保存、发布、创建等动作保留明确按钮。桌面每个操作区突出一个主要动作。手机目标点击区域至少 44px，视觉上仍可轻巧。

悬停反馈使用颜色、细下划线或边框变化，避免整行文字变淡影响阅读。选中状态同时用形状或下划线与颜色表达。键盘焦点可见，菜单支持关闭与焦点返回。

暗色模式延续当前主题功能，按相同层级映射已有深色变量，逐页检查边线、文本、弹层和图片注释，不用全局反色。

## 5. 全局导航方案

桌面建议：

```text
映墨    首页  漫游  文章  随记  合集  更多⌄    搜索  写作  通知  我的⌄
```

“更多”收纳归档、分类、标签，面板中明确列出名称；归档页和文章筛选继续提供分类、标签入口。“我的”收纳我的空间、设置、主题、管理员入口及退出。管理员入口依然按现有角色显示。

手机建议：左侧映墨，右侧写作、通知、菜单。菜单分成“阅读内容”“查找内容”“我的空间”，让全部现有路由仍可找到。随着导航内容变宽提前进入收纳模式，不等待文字挤压。

这是减少一级入口数量的提案，会改变部分功能的入口位置，但不删除路由。审查重点：归档是否需作为常驻一级入口；若需要，保留归档并把随记归入阅读分组是备选，第一轮原型优先展示上述默认方案。

## 6. 页面方案

### 6.1 登录后首页：让记录尽快进入视野

主任务是快速写一则随记，以及接着阅读朋友的内容。首页降低展示性，保持使用频率所需的直接性。

```text
全站导航

你的映墨                          往年今日 · 漫游
今天，也留下一点记录。             （一行辅助说明）

            [ 写下此刻……                   ]
            [ 附件 / 可见范围       发布随记 ]

时间流                            全部  随记  文章
───────────────────────────────────────────
今天        作者 · 时间
            随记文字
            照片（有图才展示）
            评论等已有操作

昨天        作者 · 时间
            文章标题
            摘要                     小封面
───────────────────────────────────────────
            往年今日：一则真实回忆（有数据时）
```

日期栏初始约 88–104px；右侧正文宽度按剩余空间分配，文字自身设阅读宽度上限。输入框和条目正文左边缘对齐。手机日期成为条目上方的小标签。

删除重复“刚刚发生”开场，把前四条主稿拼版改为顺序内容流；文章通过标题层级和封面获得识别，随记按文字、媒体自然展开。同一天日期合并显示，不靠随机左右错位制造节奏。

保留随记输入组件与上传、可见范围等能力；第一轮只压缩外围，不先增加折叠编辑器的新交互。回忆插页使用已有数据与出现条件，体量小于主要内容。

验收目标：在 1440×900 和 390×844、默认字号、输入区为空且无临时通知时，首屏可看到第一条记录的作者及标题或正文开头。这是原型验收目标，并非当前测量结果；长昵称和通知出现时允许自然向下延伸。

### 6.2 文章列表：保留刊物感，提高扫描效率

```text
文章                             文章总数（小字）
记录思考，慢慢展开。

作者 / 分类 / 标签 / 合集筛选       当前条件 · 清除
───────────────────────────────────────────
日期        首篇文章标题           封面（可选）
            较完整摘要
            作者 · 分类
───────────────────────────────────────────
日期        下一篇文章标题                     →
            两行以内摘要
            作者 · 分类
日期        下一篇文章标题                     →
            ……
分页
```

默认第一页且无筛选时，允许首条略大，后续统一目录行；不再为首条旁边额外建立“推荐篇目”侧栏。首条称谓保持中性，不将普通排序结果包装成推荐。

有筛选或翻页后使用同等级目录行，便于比较查找结果。保留当前筛选条件、分页和 URL 状态。日期栏约 96px；普通条目封面存在时约 120–144px，可缺省而不留空框。

图片区与文字区之间不覆盖标题。长标题自然换行；信息次序为标题、摘要、作者与分类，热度与其他已有信息弱化到辅助位置。

### 6.3 随记列表：保持时间性，呈现真实生活

沿用年份／月份组织与接口顺序，正文起始线统一。取消无意义的偏移、重复边框与英文标记。短文字条目保持短，不用统一高度撑开。

图片预览复用现有媒体组件：单图限制最大高度但保留主体，多图保持现有可辨认顺序和打开行为；长图与超宽图在预览中适度裁切，原图通过现有查看器完整打开。Live Photo 的播放标识与控制继续可用。

首页强调新内容连续阅读；随记专页强调按时间筛选和回看。二者共享条目语言，各自保留页面任务。

### 6.4 文章与随记详情：集中阅读

文章采用“窄目录＋阅读列”。标题、摘要、作者日期与正文共享左边缘；封面宽度遵循阅读列，在确实需要的媒体段落允许受控扩展。

已有目录在宽屏吸附，在窄屏使用可展开入口；目录较长时自身可滚动，不遮挡内容。没有目录时正文自然居中，不保留空边栏。目录锚点、顶部导航与移动端展开区域共用高度规则，避免标题被遮住。

正文分节、引用、代码、图片说明按阅读层级细化。表格和代码在自身区域横向滚动。评论、相邻文章与继续阅读放在正文后，通过间距与细线分段；阅读过程减少常驻侧边操作的视觉重量。

随记详情保留记录自身的体量，突出作者、时间、文字与影像，不强行增加文章式大标题封面。

### 6.5 合集列表与详情：保留书册感，改善可发现性

当前合集列表一页最多 20 项，以横向书架承载。建议改成可纵向浏览的书册列表：桌面两列、手机一列，每册为“小封面＋标题简介”的横向组合。书册封面保留轻微纸张感，减少厚重立体装饰；不再用空书位补满画面。

排序继续按既有更新时间，页码与总量仍可见，不把普通首册当成精选。没有封面时用现有标题、少量文字和纸色生成可读的文字封面，不自动抓取成员照片。

合集详情保留已有概览、时间轴与影像视图：上方“封面＋名称／简介／投稿入口”形成一个完整开场，下方选项卡稳定切换。共同署名位于辅助栏；通知偏好和管理动作降低视觉权重但保持明确可达。

已有关键记录可以形成主次组合，因为它们有真实的挑选依据。共同影像视图展示照片原色与来源，继续使用现有受保护媒体加载与权限判断。

### 6.6 漫游：全站最适合尝试编辑构图的位置

保留现有接口中的文章、随记、标签、合集、回忆和成员模块，使用清楚的三个节奏：一篇主要文章与少量辅助篇目；一组生活片段；紧凑标签与合集索引。回忆与成员作为后续段落。

页头缩成标题、短说明与“换一批内容”。数量统计变小，减少技术说明。不同模块可用不同布局，但共享分隔线、左边缘和标题尺度。

同一批内容的排列稳定，“换一批”后才更新；避免加载过程中反复变位。某类为空时收起其展示构图，只保留必要状态，不以假内容补版。全部为空则显示一个统一空状态和可用导航。

### 6.7 个人主页：从资料栏变成简洁个人页

采用“姓名／简介为主，头像为辅”的两栏开场，显示现有所在地和可见数量；数字保持注脚级，不做大指标。下方用统一内容目录与共同合集模块，沿用现有独立分页。

第一轮只使用头像、简介、地区与现有内容字段。无头像用现有文字回退，无简介降低开场高度。个人照片拼贴作为可选的第二轮设计，需要明确用户选择素材的能力；不从当前分页内容临时抽图，也不自动生成他人的生活照片。

### 6.8 往年今日与年度回顾：集中使用情绪表达

日期或年份建立主标题，统计收成一行辅助信息，照片与真实记录成为主角。年度月份轨迹保持可读，优先清楚表达已有数据。

已有可见媒体足够时，可在回顾展示区试 2–3 张图的轻微重叠；主图清楚、来源可追溯，手机回到正常文档流。无图时使用日期与文字构图，页面不留下拼贴空洞。未经数据核实不添加“最常去”“年度最爱”等总结。

### 6.9 归档、搜索、分类与标签：建立统一查找语言

页头为小标题、简短说明与必要总量。归档保留年月边栏和结果区；手机把年月选择放到结果之前。搜索输入框与结果标题左边缘一致。分类、标签使用可扫描目录，不用装饰性词云作为唯一入口。

筛选在折叠时仍显示已选条件和清除入口。查找结果统一使用紧凑目录行，区分初始无内容与当前条件无结果。返回后保持已有搜索词、页码与位置行为。

### 6.10 写作、我的空间与管理页面：统一基础 UI

写作保留已有写作画布、预览与文稿信息侧栏，明确正文、保存状态、发布动作三个等级。优先处理间距、窄屏工具栏与标签可读性，不在本轮重排发布流程或自动保存机制。

我的空间以常用任务与已有内容数量组成清楚入口。通知、收藏、设置、登录与后台页面沿用操作型布局：统一页头、表单、按钮、列表行与反馈，不套用展示型 Hero 或影像拼贴。编辑冲突、离线恢复、发布范围和错误提示保留在决策发生处。

### 6.11 公开入口与关于页：允许更完整的品牌表达

公开入口保留映墨名称、简短介绍、邀请码注册和登录。可采用左侧介绍、右侧纸页图文的非对称构图，右侧使用公开品牌素材或明确标为示意的虚构内容。

不在公开页调用受保护的成员照片、文章或统计。关于页用短章节解释记录理念和使用方式，减少面向用户的后端权限实现说明，但明确邀请制和内容可见范围。

## 7. 内容与异常状态是版式的一部分

| 情况 | 布局处理 |
| --- | --- |
| 只有 1 条内容 | 单条自然展开，不保留辅助篇目空栏 |
| 2–3 条内容 | 使用正常列表或能够自然成立的组合，不补假卡片 |
| 无封面、媒体加载失败 | 文字构图完整；已知尺寸的媒体先保留稳定区域，失败后提供合理反馈 |
| 长中文标题、长昵称 | 自然换行，不挤压操作或超出屏幕 |
| 多标签 | 列表优先少量关键标签，其余通过详情或已有展开入口查看 |
| 无筛选结果 | 保留条件，提供清除，不误称整个空间为空 |
| 加载与刷新 | 使用与最终布局相近的占位；有旧数据时按现有逻辑提供局部更新反馈 |
| 权限失效 | 沿用现有错误处理，不借助封面、摘要或数量暗示不可见内容 |
| 放大文字与键盘访问 | 200% 缩放可用，菜单、筛选、编辑与媒体操作能到达 |

## 8. 实现边界与技术落点

主要改动位置：AppShell 的导航分组；HomePage / HomeFeed 的层级与排列；PostsPage 的列表组合；PostCard 与各类 FeedPost 的表现；SectionHeader 的统一；阅读、合集、个人主页的局部布局；样式文件按基础规则、共享布局与页面范围逐步整理。

不直接把参考 HTML 嵌入项目，也不引入第二套组件库。优先复用已有受保护图片、媒体查看器、目录、输入器、筛选和分页组件。

首页布局变化需要重新验证滚动锚点、筛选缓存、发布后插入位置和加载更多。列表变化需要验证链接、交互元素互不嵌套冲突、分页与 URL 状态。吸附定位统一读取导航高度，不继续分散写死偏移量。

第一轮不要求新增后端字段。个人可配置拼贴等需要新素材选择能力的想法单独排期，不作为基础改版前提。

## 9. 分阶段交付

### 阶段 A：设计审查（当前）

交付本方案。审查视觉保留范围、导航分组、首页时间流、合集纵向列表和长文排版例外。

### 阶段 B：关键页面视觉样板

采用明确标注的示例内容，先制作文章列表、首页和文章详情的桌面／手机样板；同批内容比较长标题、有图、无图。样板显示暖纸色、实际中文字体、按钮和真实密度，不能只有空白线框。

样板通过后形成布局规范及与 DESIGN.md 的明确修订清单。照片拼贴此阶段不作为核心依赖。

### 阶段 C：核心阅读路径实现

先整理必要共享样式并交付文章列表，再接入导航分组、首页、随记与详情页。每页完成视觉和功能验证后再扩展，避免基础样式一次改动波及所有页面。

### 阶段 D：内容组织与展示页面

合集、漫游、个人主页、归档、搜索、分类标签依次统一；往年今日与年度回顾加入经过验证的局部影像构图；公开入口与关于页使用独立公开素材。

### 阶段 E：操作页面与全站收尾

写作、我的空间、通知、设置、登录、后台统一基础 UI，集中验证主题、可访问性与媒体。清理已废弃的页面样式，交付最终规范、页面对照及已知限制。

## 10. 验收标准

- 识别度：暖纸色、中文字体、墨蓝仍能清楚识别为现有映墨。
- 主次：首页尽早进入记录；展示性大标题只出现在适当页面。
- 连续性：同类内容共享起始线、元信息位置、筛选与分页语言。
- 完整性：真实长内容、空状态、缺图和少数据仍能形成完整布局。
- 使用：全部现有功能可达，手机不会因留白或分栏增加不必要操作。
- 阅读：目录、正文、代码、图片与评论在不同屏宽下清楚可用。
- 状态：筛选恢复、分页、时间流锚点、媒体与草稿保存按既有能力工作。
- 风格克制：装饰对理解或情绪表达有作用，不出现每页都套同一种巨型开场。
