# 映墨前端设计规范

写作器实现约束：单个 Tiptap 文稿承载文字与站内图片节点，仍保存 Markdown 与 `[[ym-media:ID]]`。源码与可视模式切换保留公式、脚注和 HTML 等原文；图片移动、复制、删除与上传进入同一文稿的撤销历史，删除节点不删除媒体文件。发布前集中选择合集、标签与阅读范围；取消或失败保留选择与草稿。标签推荐、搜索和引用计数始终服从当前成员权限。

> 状态：现行规范
>
> 适用范围：登录、注册、内容浏览、阅读、写作、个人空间、设置与管理后台
>
> 设计基准：现有登录／注册页与“编辑纸页”原型

本文是映墨前端视觉与交互的唯一设计依据。其他提案、评审和历史原型只提供背景，不覆盖本文规则。新增页面不得再建立独立的视觉体系；确需修改规范时，直接更新本文，不另建同类设计文档。

## 1. 产品气质

映墨是一个安静的私人记录与朋友共同回忆空间，不是资讯门户，也不是效率后台。

视觉关键词：

- 暖纸、墨字、留白、细线。
- 中文宋体承担主要阅读与层级。
- 黑白品牌影像与少量深蓝手写痕迹形成辨识度。
- 内容本身比界面容器更重要。
- 克制但不冷淡，编辑感但不牺牲可用性。

所有页面必须像出自同一本刊物，但不必使用相同构图。登录页可以有叙事和影像；设置、写作与后台应更直接，只共享颜色、字体、控件和节奏。

## 2. 不可破坏的原则

1. 页面使用暖纸色，不使用纯白或冷灰作为大面积背景。
2. 标题、正文、导航和表单以同一中文衬线字体为主。
3. 主操作使用近黑色；深蓝只用于链接、焦点、选中线和手写点缀。
4. 内容区域优先使用留白、对齐和文字层级，必要时使用分隔线，不堆叠通用卡片或重复横线。
5. 普通容器保持直角；圆形只用于头像、图标按钮和确有语义的状态点。
6. 普通内容不使用阴影。阴影只属于菜单、浮层、弹窗和图片查看器。
7. 手绘线稿和手写短句可以在同一页面形成呼应，但必须留有呼吸感，且不能承载必要信息。
8. 用户照片默认保持原色；黑白处理仅用于登录、品牌拼贴和明确策展的封面。
9. 移动端首先保证阅读和操作，不把桌面页面简单缩小。
10. 任何视觉调整不得破坏权限、可见范围、保存状态、错误反馈和媒体能力。

以下值是全站基准。页面不得自行声明近似色制造第二套主题。

  --ink: #242520;
  --ink-secondary: #41423c;

状态色只用于真实状态，不作为装饰。若保留深色模式，它是同一系统的兼容呈现：使用暖炭黑而非纯黑，结构、字号和层级不得改变。

## 4. 字体与层级

中文是主要排版语言。标题和正文使用 `--serif`；等宽字体只用于代码、编号或需要对齐的数字。手写字体只用于装饰性短句。

| 角色 | 桌面 | 手机 | 字重 | 行高 |
|---|---:|---:|---:|---:|
| 品牌大字 | 72–112px | 58–72px | 400 | 1.10–1.20 |
| 页面标题 | 40–56px | 30–38px | 400 | 1.25–1.40 |
| 阅读标题 | 46–60px | 32–40px | 400 | 1.30–1.45 |
| 区块标题 | 22–30px | 20–26px | 400–500 | 1.35 |
| 列表标题 | 17–24px | 17–21px | 400–500 | 1.45 |
| 阅读正文 | 17–19px | 16–18px | 400 | 1.75–1.90 |
| 界面正文 | 14–16px | 14–16px | 400 | 1.55–1.75 |
| 标签／元信息 | 10–13px | 10–12px | 400–500 | 1.40–1.60 |

规则：

- 中文标题使用轻字重和字号建立层级，不使用 700 以上粗体。
- 正文默认字间距 `0.02em`；大标题可使用 `0.04em–0.08em`。
- 英文眉题允许大写及 `0.12em–0.22em` 字间距。
- 日期、统计和并列数字使用 `font-variant-numeric: tabular-nums`。
- 链接应通过颜色或下划线被识别，不能只依赖悬停。
- 长标题自然换行，不以固定高度裁掉文字。

## 5. 页面骨架

### 5.1 桌面端

- 内容最大宽度 `1280px`，左右内边距通常为 `48–64px`。
- 阅读正文最大宽度 `720px`；不为了填满宽屏而拉长行宽。
- 全局顶栏保持轻薄，以细线分隔，不悬浮成卡片。
- 一级导航收敛为：`首页 / 漫游 / 合集 / 查找`，之后以细线分组 `写作 / 通知 / 我的`。
- 文章、随记、分类、标签、归档与搜索属于“查找”，不是七个同级品牌入口。

### 5.2 移动端

- 页面水平内边距通常为 `20–24px`。
- 顶栏承载品牌、返回、页面标题、搜索及上下文操作。右侧固定为搜索、通知和“更多”；“更多”不重复搜索与通知，并在底部提供主题切换（跟随系统／浅色／深色）和退出登录。
- 登录后的稳定底部导航为：`首页 / 发现 / 写作 / 我的`。
- 底栏保留连续暖纸底，使用 24px 统一线性图标与 12px 文字。当前入口以靛蓝和文字下方的小圆点标记；只让图形轻抬 2px、按压缩小及松开回弹，文字、未读角标和点击区域保持稳定。不拦截原生链接、延迟导航或以滑动手指切换入口；唯一例外是已在当前入口页面且向下滚动时，再次点按平滑回到顶部。减少动态时取消位移与回弹，回到顶部也直接跳转。
- 底部导航包含安全区，正文必须预留对应空间。
- 顶栏高度统一包含内容行、顶部安全区和边线，吸顶导航与定位偏移共用该高度。页面启用 `viewport-fit=cover`，横屏内容避开左右安全区；手机与触控设备的文字输入不小于16px，保留页面缩放。系统键盘展开时收起底部导航，写作操作栏、文稿抽屉与输入弹层按实际可见视口定位，关闭键盘后恢复。
- 主要触控目标不小于 `44 × 44px`。
- 手机阅读设置、内容与合集筛选、“我的帖子”更多操作使用共用暖纸底部面板，正文可独立滚动并避开安全区与键盘。支持点外、Escape、显式按钮与把手下拖关闭；关闭后还焦点，减少动态时取消拖动回位动画。筛选在面板内暂存多项选择，点“查看结果”一起应用，取消保留原条件。
- 评论键盘展开时，将回复对象、字数与发送入口放在键盘上方，输入框为操作栏留出空间。未发送文字、回复对象和提及保存在当前会话内存，按账号和帖子隔离；往返页面继续编辑，退出或会话失效时清除。发送中的状态一起保留，成功才清除草稿，失败恢复，不因往返重复发送。
- 搜索、收藏、合集目录及合集时间轴与影像列表在历史返回时保留 URL 查询条件、页码与所点条目的阅读位置；先重新读取并校验权限，列表出现后再定位。仅在会话内记位置，不持久化成员内容，用户主动滚动后停止校正。
- 手机写作工具栏保留图片、加粗、链接，其余格式放入“更多”；源码与可视编辑使用同一个切换入口，沉浸入口常显。菜单避开可见视口边缘，点外或按 Escape 关闭，Escape 后焦点回到入口。
- 对话框、文稿抽屉和灯箱共用嵌套滚动锁，只由最上层响应关闭与焦点循环。隐藏、禁用的控件不参与 Tab 顺序，关闭后焦点回到仍在页面中的原入口；下拉框先独立响应 Escape，不同时关闭外层弹层。弹层内部滚动不传递到背景页面。
- 不使用汉堡菜单隐藏四个最高频入口；低频入口放入“我的”或“发现”。

### 5.3 空间节奏

只使用以下间距级别：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96px`。

- 相关文字：`8–16px`。
- 单个组件内部：`12–24px`。
- 列表条目之间：`20–32px`，配合细线。
- 页面区块之间：`48–72px`。
- 展示型开场最多占桌面首屏的三分之二；登录后的首页应尽快出现真实内容和记录入口。
- 手机（≤767px）不把桌面开场线稿原样缩小，而是为每页重新做一处紧凑构图，真实内容或搜索框仍须进入首屏：首页、文章、随记、合集目录、搜索、分类与标签目录都把缩小的线稿放在标题右侧（宽约 104–218px），数量、切换、筛选或搜索框排在下一行，文章与随记保留各自的手写短句；个人主页的签名线稿缩到约 100px 浮在姓名右侧；我的内容、收藏、我的评论、我的媒体和年度回顾的页头以 `.has-phone-sketch` 把约 104px 的线稿放回标题右侧，页面出现带插画的空状态时收起页头线稿，一屏只留一幅墨团。归档用时间标尺代替线稿；分类与标签详情、设置、登录设备、新建与管理合集、修订记录和后台等工作页仍只保留标题。手机的装饰同样不超过可视区域的 15%，不用横线替代被删掉的插画。

## 6. 组件规则

### 6.1 按钮

- 主按钮：近黑底、暖纸文字、直角或 `2px` 圆角。
- 次按钮：透明底、近黑细边框。
- 文字按钮：无容器，通过文字和箭头表达动作。
- 危险按钮：仅在删除、撤销权限等危险动作中使用暗红色。
- 每个局部区域只保留一个最强主操作。
- 深蓝色不作为大面积主按钮背景。
- 共享控件样式不依赖页面容器；通过 Portal 挂载到 `body` 的弹窗按钮与页面内按钮保持一致。按钮和下拉选项使用 `--radius-control`，确认弹窗和下拉浮层使用 `--radius-overlay`，浮层保留必要阴影。

### 6.2 输入框

- 登录、注册、搜索和轻量输入优先使用底部细线。
- 设置、后台和复杂编辑器可以使用完整边框，但保持直角和透明／纸色背景。
- 聚焦状态使用 `2px` 深蓝轮廓或加深底线，不能只改变细微颜色。
- 标签、帮助、错误文字始终靠近对应字段。
- 错误使用暗红文字和边线，不用整块高饱和背景。

### 6.3 内容容器

- 文章、随记和合集列表默认是连续目录行，不是卡片墙。
- 区块先通过留白、对齐和标题层级建立结构；仍需明确边界时，再使用 `1px` 分隔线。
- 同一处内容边界只保留一条必要的线，避免父容器底线、下一节顶线、标题底线连续叠加。眉题旁的延长线、首篇上下边线和列表末尾横线若没有独立作用，应删除。
- 连续目录可保留辅助逐行阅读的细线，但不要让所有标题、容器和空白区域都带横线。验收时同时检查有图和无图内容，避免无图页面退化成一串平行线。
- 先减少冗余线条，再以少量手绘点缀丰富节奏；装饰不能成为保留多余边框的理由。
- 只有菜单、弹窗、通知浮层等真正覆盖页面的组件才使用悬浮容器。
- 不为空数据制造装饰性占位卡片。

### 6.4 标签与状态

- 标签优先使用纯文字、前缀或浅纸色小矩形。
- 不使用大量胶囊标签。
- 选中状态以深蓝文字、短下划线或底边线表示。
- 状态文案必须直接说明含义，例如“仅自己可见”“草稿已保存”。

### 6.5 图片与手写标记

- 品牌影像：黑白、低对比、生活化，不使用商业图库式人物摆拍。
- 用户内容：忠实呈现原图，不为统一风格强制灰度。
- 列表缩略图只显示第一张时，用角标标出 Live Photo 和随记的图片总数（如“LIVE”“3 张”），角标不可单独点击。
- 图片按实际显示尺寸与屏幕像素密度在缩略图（长边 640px）和展示图之间选择：缩略图放大超过 1.5 倍才改用展示图，小位置不加载展示图。
- 多图随记的列表缩略图点开后是这则随记的全部照片，可左右翻页，计数显示“1 / N”；读取期间入口标为忙碌，不另加加载提示。灯箱里的顺序与页面阅读顺序一致，点封面从“1 / N”开始。
- 正文与媒体列表中的 Live Photo 是一个条目：静态图上叠放动态片段并带 LIVE 标识，触屏长按画面或按住 LIVE 播放、松手停止，轻点画面仍打开灯箱；动态片段在首次交互时才读取。
- 图片默认直角；拼贴最多轻微重叠或极小角度旋转。（列表、正文、封面与媒体列表中的用户图片均为直角。）
- 手机随记目录中的配图按原图比例显示（限制在 3:4 到 16:9 之间），顺序为正文 → 图片 → 作者与地点 → 标签。
- 手机合集的共同影像是集邮册：每张照片是一枚齿孔邮票，横图（宽高比 ≥ 1.2）占两格，竖图和方图占一格，比例收在 3:4 到 8:5 之间；齿孔用遮罩挖出，底色是略深于页面的册页，照片保持原色。点开一枚从底部升起一张纸：邮票放大，延迟盖上靛蓝邮戳（环字为地点 · 映墨 · 记录者，中间是发生日期和年份）与波浪注销线，邮戳一半盖在邮票外；下面是标题（无标题随记用正文开头）、作者、日期、地点和“查看原图”“查看原记录”。左右滑动或方向键换一枚，向下拖或点收起按钮让纸滑下去关闭；查看原图打开同一灯箱，叠在这张纸上。减少动态效果时去掉升起、盖章和滑动动画。桌面仍用原影像墙。
- 邮票齿孔只用于手机共同影像，不扩展到其他图片位置。
- 不使用胶带、贴纸、厚相框、强阴影和撕纸装饰堆叠。
- 品牌装饰优先使用原创手绘线稿、墨迹轮廓与手写短句，不用无语义照片直接填补留白。
- 手绘元素使用代码内 SVG 或项目自有资产；线条保留轻微不规则感，不使用通用图标库拼成插画。
- 近黑线稿负责主体，`--ink-blue` 只用于短句、箭头或一两笔呼应；整组装饰不超过可视区域的 15%。
- 所有手绘装饰设置 `aria-hidden="true"`，不得影响正文对比度、点击区域或移动端首要任务。

### 6.6 图标与反馈

- 图标使用统一线性风格，描边粗细一致。
- 不用 emoji 充当正式操作图标。
- 加载、空状态、错误和成功反馈保持简洁，但必须明确下一步。
- 骨架屏只用于页面首次加载。切换筛选、翻页或操作后重新读取时保留旧内容，超过约 150ms 才淡化并暂停点按，页头、筛选与焦点保持不动。
- 收藏、回应等轻量互动点按即生效，失败时恢复原状态并说明原因；请求进行中按钮不变灰、不改文案。
- 发布随记时，在“发布到”下方用一句话说明谁能读到（仅自己 / 所有映墨成员 / 合集成员）。
- 新成员首页的“第一封信”沿用信纸排版：眉题、问候、一条细线和带编号的三件小事，配手绘寄信线稿，不做卡片或弹窗。
- 触屏点按正文里的链接与文字按钮时，以文字变淡作为按下反馈，松手即恢复；不加底色或阴影。
- 系统通知和弹窗不得遮住顶栏、底部导航或主要提交按钮。

## 7. 页面类型

### 品牌与认证页

允许大留白、黑白影像、手写短句和非对称构图。表单仍需清晰直接。登录成功后的首页必须延续相同纸色、字体和控件，避免视觉跳变。

欢迎页采用与登录页相同的连续纸底、宋体和留白：主标题以墨色稳定排成两行，右侧只保留一幅较小的原始推门墨团线稿；去掉纸纹、印章、竖排页码、手写空位与装饰性下划线。主入口为墨色“进入映墨”，前往登录；邀请码注册以“有邀请码？加入我们”文字入口承接。下方用三段开放文字说明记录、共同合集和往年今日，取消编号图标组与重复的深色注册宣传区。页脚保留邀请制与登录后阅读说明。移动端主入口先于缩小插画，导航、字体放大与深浅主题继续可用。

已有登录状态的访客从欢迎入口打开网站时，以“翻开封面”自动进入首页：确认状态期间完整显示静态欢迎页，确认成功后右下角沿同一折线翻走，550ms 完成，不增加角色表演或额外等待。首页模块预载与导航并行，慢数据保留真实首页加载/错误状态；确认失败留在欢迎页，确认期间离开也不拉回。自动进入替换欢迎页历史记录，同一应用会话只演一次，站内链接进入欢迎路由直接回首页，刷新首页不播放。减少动态时直接导航，缩放/返回/页面隐藏与登录翻页共用清理逻辑。开发预览 `/dev/login-page-turn?from=welcome` 可与认证成功撕纸对照。

登录页沿用捧书墨团的原始 SVG 轮廓，以头部、眼睛、手、书和书签分层响应操作：桌面鼠标只触发小幅视线与偏头，聚焦用户名时探头，聚焦密码时低头读书。密码框右侧提供 44px 点击区域的显隐按钮，支持键盘、保留输入与选区；显示密码时书抬高并遮住面部，该状态优先于鼠标、输入、等待和错误状态，直到重新隐藏。错误仍由就近文字说明，墨团仅轻微歪头。触控不跟随指针；减少动态时取消位移与动画，以即时姿势保留密码显隐反馈。组件不接收用户名或密码内容。

真实登录或注册成功后的页面切换使用一次撕纸转场：裂口从提交按钮上方延伸约700ms，再让两半纸页带不规则毛边与轻薄投影向两侧倾斜分开约1200ms，真实目标页在下方正常加载。只在认证请求成功后播放，不改变登录的 next 完整路径、查询与片段，也不改变注册后的首页／邮箱验证分流。表单内容在临时副本中清空并替换，不复制用户名、密码、邮箱或邀请码；注册副本显示“已注册”，登录显示“已登录”。临时副本无交互并从读屏树移除，完成后释放并将焦点交给目标标题。请求失败保留原表单；减少动态时直接导航。缩放、返回、页面隐藏或偏好变化立即清理，超时释放，不留下不可操作的遮罩。动作参考 Codrops Interlude 的 MIT 开源 tear，几何和节奏移植为原生 rAF，不引入 Astro、GSAP 或 Three.js；许可位于 `frontend/public/licenses/interlude-MIT.txt`。开发预览 `/dev/login-page-turn` 可反复播放撕纸，`?motion=turn` 对照原翻页，生产包不包含预览页面。

### 版本更新提示

全站新版提示采用居中的暖纸对话框，宋体标题“映墨有更新了。”，配墨团捧来新纸页的独立 SVG 线稿，深蓝只用于纸页上方刷新线与少量动势。桌面宽480px，手机保留16px边距与至少44px操作热区，深浅主题同构，插画保持静态。新版安装开始即可提示正在准备，就绪后才启用墨色“刷新更新”；“稍后再说”与关闭入口始终明确，不自动刷新。打开时焦点放在标题，Tab在弹层内循环，Escape关闭后返回原焦点；同一版本稍后就绪不再次打断。首次离线安装不弹更新提示，失败就近说明并支持重试。

### 首页与浏览页

首页先服务“写下一笔”和“读到朋友”，真实内容应在首屏尽早出现。文章、随记、合集和归档优先使用编辑式目录、时间流或书册结构，不使用等高卡片网格填满页面。

首页保留真实文章与随记的连续目录、日期、筛选和阅读入口，正文不参与图案绕排。卷首插画采用已确认的钢笔长椅：笔杆作座、笔夹作靠背，两位朋友坐在同一支笔上交谈；使用项目内粗墨位图，保留完整人物与笔尖，真实用户照片继续保持原色。手机把“朋友的／近况”排成两行，钢笔长椅缩到约 218px 放在标题右侧，与标题底部对齐，两位朋友坐在标题旁；页边小物不显示，最近记录无封面时不显示占位插画。手机侧栏排在无限加载的时间流之后，几乎无法到达，因此“共同记录”改为时间流第 6 条之后的插页（不足 6 条时排在最后一条之后）：左侧合集线稿，右侧靛蓝小标题、最多两本合集与“查看合集”，链接保持 44px 热区；有插页时侧栏不再重复共同记录，没有合集时不出插页。桌面与平板仍用侧栏。

系统管理员通过“后台／内容”的“置顶到首页／取消置顶”挑选文章，通过“后台／精选”的“上移／下移”安排顺序。首页最多展示3篇当前成员有权阅读的置顶文章：第一篇进入既有卷首主推并标记“置顶推荐”，后两篇以标题、作者和轻量“置顶”文字形成连续目录，不增加独立卡片或轮播。手机保留44px链接热区与完整标题换行；没有可读置顶时沿用最近记录主推。置顶独立于最近记录的类型筛选，不改变文章时间；时间流与回忆插页不重复展示置顶文章。归档、隐藏、删除及失去权限后退出展示，重新读取与翻页时继续由服务端判断。

续火花入口位于首页内容区最上方，先于卷首、快速随记和时间流，手机首屏直接可见，也可从“我的”进入；不悬浮、不遮挡内容。入口以宋体“续火花”、“抖音好友的每日问候”说明和“进入”长箭头组成清楚层级，整块为同一个原生链接。左侧沿用已确认的粗墨小墨团开门图案：靛蓝火柴兼作门把手，门、墨团与手臂以分层 SVG 呈现，轮廓有粗细变化并跟随深浅主题。已连接抖音并选了好友时，说明下方加一行当天进度“今日已续 N / 总数 · 最长 X 天”，只统计确认送达的好友，最长取所选好友中最大的火花天数。本机记住上次看到的数字：每天第一次打开首页时，数字像计数器一样逐位从上次的值滚到当前值（约560ms，高位依次晚60ms）；当天全部续上后，一枚深蓝“已续”小印盖在门画右下角，像画上的落款，当天第一次看到时由大到小按下并微微回弹（约380ms），之后静止显示。续火花页的好友列表沿用同一滚动数字，当天确认送达的好友在天数前带一枚小印，页面开着时刚送达才盖下去。进度与印章随整块链接的读屏名称一起朗读，减少动态时直接显示结果。精细指针悬停时约180ms开门，移开可收回；普通点击后墨团约280ms走入再进入工具，触控先开门再走入，一次点按即可完成。意图明确时预载工具页面；键盘、修改键、新标签和减少动态直接保留链接导航。重复点按只执行一次；Escape、返回、页面隐藏或离开立即清理待执行动作，不留下导航锁。

页边小物从信纸小船、铅笔花、聊天茶杯、相机与心形肩带、信封小山、胶片和书页小路中随机选取，按可用留白限量展示。小物使用独立装饰层，不改变正文、卡片或控件布局；放置与拖动均避开标题、段落、记录行、用户影像及操作区域。鼠标拖动实时跟随，松手即停，支持方向键移动和 Home／Escape 归位，不自动漂浮；触控保留静态点缀。提供“换一组小物”和“收起／显示小物”，收起偏好仅保存在当前浏览器会话。装饰图从读屏树隐藏，主动操控的小物保留清楚的键盘名称与焦点。平板减少数量，手机不显示，深色主题只适配品牌墨绘，不能反转用户照片。失焦或页面隐藏时停止拖动，离开首页释放装饰层和观察器。

#### 文章页：沿着档案横线跑动的小猫

`/articles` 在“文章档案”上方保留一条横线，让它同时成为小猫行走的地面。这个点缀为首篇阅读与档案目录之间提供轻巧的过渡，使结构线也能带有生活气息。先移除首篇周围及档案前重复的横线，再保留这一处互动，不在每条分隔线上复制装饰。

- 造型以已确认的五张小猫原型为依据：近黑细线轮廓、尖耳、细胡须、弯曲翘尾，身体内部留白，以少量深蓝短线表达动势。使用代码内 SVG，保持缩小后的辨识度，并适配纸色与深色主题。
- 鼠标在小猫左侧时向左跑，在右侧时向右跑，转身朝向行进方向；靠近鼠标的横向位置后停下，到达横线边缘不得越界。
- 跑动使用站姿、伸展、收腿、腾空、落地等五个全身姿势组成约 `600ms` 的循环，避免只摆动四肢。停下后恢复站姿，动势线随之收起。
- 小猫始终沿横线移动，不追随鼠标上下移动，不遮挡文章标题、目录或链接，也不改变内容布局。它是可偶然发现的趣味，不承担导航或必要信息。
- 触控操作不触发追随，保留静态线稿；开启“减少动态效果”时停止追随与姿势动画。窗口失焦或页面隐藏时停止跑动。
- 装饰使用 `aria-hidden="true"` 和 `pointer-events: none`，不进入键盘焦点顺序，不拦截点击或滑动。缩窄窗口时小猫仍须限制在横线内，不产生横向滚动。

#### 随记页：连续的日常手账

`/notes` 使用单列内容流，桌面侧栏标注年份与月份范围，每则随记以日期引出正文。年份之间通过留白区分，同一年内仅在相邻条目之间保留一条细线，取消双列围框、首条底色和重复边界。有图与无图条目共享文字层级，不因首条位置而放大正文。

页头以纸飞机线稿和少量深蓝虚线呼应“一闪而过的念头”，保持静态，不复制文章页的小猫互动。筛选默认收起，展开后保留作者、标签、合集和排序能力。用户照片保持原色，桌面位于文字右侧，窄屏移到正文下方；作者、发生时间、地点、心情及内容关联入口继续保留。

#### 归档页：按年月翻阅的时间目录

`/archive` 与文章、随记共用浅色纸面底色，避免回退到偏黄的旧主题。页头使用旧卷册线稿与少量深蓝书签点缀；范围、记录数和年份数以文字统计呈现，不为每项统计增加边框。作者、分类、标签与合集筛选默认收起，收起时仍显示已启用条件的数量。

桌面保留左侧年份与月份索引，右侧以年月标题组织连续记录；窄屏把时间索引移至内容上方。手机上只要有两个及以上月份有记录，就用一把手绘时间标尺代替横向年份条和月份格：从最早一年的一月排到最近有记录的月份，每月一道刻度，空月只留细短刻度，有记录的月份按记录数的平方根加高，一月刻度略长作年份记号，刻度下方是可点的年份；顶部“全部”回到全部时间。手指横向拖动或点按时浮出“2025 年 06 月 · 2 则”小签并吸附到最近的有记录月份，其余刻度变淡，松手才换范围；竖向滑动仍滚动页面。当前月份用深蓝小书签标出，只选年份时在该年刻度下画一条深蓝细线。标尺对读屏和键盘是滑块，方向键逐个跳到有记录的月份，停手约0.45秒或按回车后换范围，Home／End 到首尾。月份之间使用留白，只在同月相邻记录之间保留细线，避免年月标题、日期和内容各自带框。文章按发布时间、随记按发生时间归组，保留原有筛选、分页、链接和权限逻辑。

#### 分类与主题页：阅读路径索引

`/categories` 将栏目呈现为连续的书脊目录，以编号、名称、简短说明和可读文章数建立层级；仅在相邻栏目之间保留细线。`/tags` 把全部标签连成一段宋体文字：按频次分三档字号，次数像脚注一样以等宽小字上标，词与词之间用顿号，末尾一个句号，不使用等高卡片格或胶囊标签。精细指针停在一个词上约 0.14 秒后，其余词退成淡墨，这个词以深蓝底线标出，段落下方翻出该标签最近一则记录的摘录、作者、来源与日期，并给出“看全部 N 则”；键盘聚焦同样触发，移开即收回，取过的预览在本页缓存。搜索标签时不匹配的词由不可交互的副本在原处淡出，留下的词从原位置平滑挪到新位置。触屏不出预览，点词直接进入标签页，每个词保持 44px 热区。两类页面共用分类签与书页线稿语言，近黑线条负责主体，深蓝只标记书签、路径和当前入口。

栏目或主题详情使用窄范围摘要与宽阅读清单。文章和随记可在主题下自然混排，编号、内容类型、标题或正文、作者及时间信息保持可辨；图片在桌面位于文字右侧，窄屏回到正文下方。页头与内容区不重复展示相同的粗线框，统计只辅助判断范围，不与分类名称争夺注意力。

#### 搜索页：从一个线索开始

`/search` 把搜索输入作为首要操作，标题、线稿与输入框形成完整的检索开场。输入框使用清晰的底线和充足字号，提交按钮保持明确；搜索建议作为临时浮层显示，支持键盘上下选择、回车确认、Esc 关闭和 `⌘/Ctrl + K` 聚焦。放大镜扫过手写行的线稿只表达“寻找”，不得挤压输入区或承载状态。

结果按“全部、文章与随记、合集、成员”切换，标签之间使用留白与当前项底线，不用完整分栏边框。文章和随记采用编号、正文、右侧缩略图的连续目录；窄屏图片移至正文下方。合集、成员、分类及标签作为辅助发现入口，视觉强度低于主要内容。搜索计数、分页、建议、空结果与 URL 查询状态必须真实且可访问，任何结果都继续遵守原有内容权限。

#### 合集详情页：一本共同书册

合集目录以书架陈列可进入的合集。书架上方是一条底线搜索框、“全部／我创建的／我参与的”文字标签（附册数）和“和谁一起”成员选择，条件写进地址，跨页同样生效；成员选项与册数按全部可进入的合集统计，不随当前筛选变化。筛选或翻页时，筛掉的书被从书架上取走（向上淡出），新进来的书从下方放上架，留下的书从原位置滑到新位置；没有结果时说明“这一格书架是空的”并提供清除筛选。点按一册书或书名先把它抽出来：书从书架飞进介绍卡，书架上留出空位；介绍卡左侧是书，右侧是名称、简介，以及创建者、成员（最多列四位，其余“等 N 位”）、记录数与起止年月、最近更新四个条目，“进入合集”沿用书册翻开动效进入详情。介绍卡可用左右键或“上一册／下一册”在当前书架里翻看，书与文字从翻动方向换入；Esc、关闭按钮或点背景时书沿原路落回空位。修改键、新标签仍保持原生链接行为。手机上介绍卡从底部升起，书在上、文字在下，进入按钮占满一行。

合集详情以“封面、卷首信息、卷内目录”为基本结构。真实封面保持原色和直角；无封面时使用项目内书页线稿、合集名称及整理日期组成专属封面。封面通过细书脊与错开的纸页边缘表达书册厚度，不使用厚阴影或圆角卡片。名称、说明、创建者、共同署名、整理时间及“写入新的记录”构成卷首，管理入口只对创建者显示。

共同时间轴、合集内容和共同影像共享一条阅读视图导航，当前视图使用深蓝底线。时间轴按真实发生时间分组，合集内容按收录顺序排列，两者都使用编号、正文与右侧缩略图的连续目录；筛选默认收起，收起时显示已启用条件数。共同影像保留疏密有别的画册布局，图片仍链接回原记录。成员、通知偏好、分页、权限、媒体查看与管理能力必须保持完整，手机把小封面放在标题左侧，无封面时只留线稿、不重复合集名称，“添加记录”保持在首屏；图片移至正文下方，视图导航可横向滚动。

合集内容是进入合集后的默认视图，并排在视图导航第一位。同层目录排在记录前面，叠成一只拉开的纸墨档案抽屉：隔页按目录顺序从后往前叠放，按同一透视比例向后收拢，越靠后越窄、目录名略小（不低于约 12.6px）、线条越淡，不用阴影、渐变和圆角。箱体由双线的侧壁顶沿、压在前脸上沿的前板顶面细纸边，以及侧壁与隔页之间露出的实墨内膛组成；内膛随深度变淡，深色主题压暗成暗面，不反成亮面。每层隔页上沿后面有一道不规则墨缝，缝里按这层目录（含子目录）的记录数露出纸边：没有记录不露，1–2 则一道，3–9 则两道，10 则以上三道；索引签立在缝前。前脸以不等厚闭合墨面和少量纸色缺口形成重量，左侧图形、目录名与数量组成档案标签，右侧保留墨绘拉手。索引签在各层错开，14px 目录名搭配小号顺序编号，含子目录的索引签填深靛蓝。桌面悬停或键盘聚焦时该层轻抬 6px，并以藏进抽屉的下沿为轴朝读者微倾约 4°，这层目录（含子目录）里最新一则记录的摘录卡从隔页里升起，卡片用墨底纸字，按最新摘录、日期、正文和来源建立层级，靛蓝小书签落在卡片边缘，内容沿用当前成员可见的合集记录，没有记录时不出卡片；抽屉前脸显示当前层或所指目录的名称与数量。抽屉用不可滚动的裁切边界收住隔页，键盘聚焦不得滚动抽屉内部或裁掉摘录顶部，鼠标离开后仍保留当前聚焦项的摘录。点击时其余隔页落下约 200ms 后进入下一层，新一层依次升起；修改键、新标签和减少动态保持原生链接行为。触屏不靠悬停：按住约 0.1 秒抽出该层，同样轻抬微倾，索引签反成墨底，前脸换成该目录的名称与数量，手指滑动或页面开始滚动即放回；轻点松手后沿用落下动效进入下一层。按满约 0.4 秒，同一张摘录卡以手机尺寸从隔页后升起，支持震动的设备轻震一次，此时索引签退回原样以和墨底卡片分开；松手放回且不进入。有摘录的隔页以长按偷看代替系统链接菜单和文字选择，没有摘录时保留系统菜单；抽屉为摘录向上借出的空间用负外边距抵消，不改变排版，也不挡住上方操作。窄窗口里的鼠标不出摘录卡。手机与触屏的索引签靠左，目录名与数量分层排布，数量和管理入口常显，长名称不得挤占管理热区。同层超过 8 个目录时，其余目录回到连续目录行。记录左侧使用同一套纸品图形：文章是折角文稿，随记是别着回形针的便笺，合集根目录是装订书册，目录是带索引签的纸套。原生矢量以不等厚闭合墨面与纸色留白表达笔压，小面积深靛蓝落在索引签、折角和装订处；桌面主图形 56px、手机 44px，目录树与移动弹窗使用同源小尺寸图形。图形从可访问树移除，标题、类型与状态仍由真实文字表达。进入下一层时顶部显示面包屑，当前层名称替换“合集内容”标题，页面不回到封面。每层标题右侧并列“新建目录”“写文章”“写随记”，手机上三等分为一条无边框的靛蓝文字工具行，按钮之间只用细竖线分隔，热区不低于 44px。新建和改名的表单出现在抽屉上方，移动用树形单选弹窗，删除在确认文案中说明内容会移到上一级。桌面右侧索引最上方是可展开的目录树，层级以细线连接，当前层用深蓝短线标记；手机隐藏目录树，只保留逐层进入和面包屑，隔页的改名、移动、删除收进“管理”底部面板，操作热区不低于 44px。

桌面可把内容或目录拖到抽屉隔页、目录行、面包屑或目录树上，只有放得下的目标才响应，并以深蓝轮廓和浅底标出，抽屉隔页同时轻抬，目标纸套切换为打开状态；拖动预览是唯一带阴影的浮层，沿用源项目图形，显示名称、类型与批量数量。目录树折叠节点停留约 650ms 后展开，右侧索引在桌面吸顶，长列表也够得到。每条可移动内容提供“移动”和“选择”，Shift 连选，Esc 取消；已有选中项时点卡片继续选择，顶部吸附操作条提供全选和“移动到…”。选中行使用浅靛蓝底和左侧短线共同标记。移动后沿用底部“撤销”提示，不用倒计时催促；触屏不启用拖拽，键盘和读屏使用“移动”弹窗。

### 阅读页

具体文章阅读页按“卷首、开篇影像、正文、篇末回应”建立完整阅读节奏。标题与摘要先形成安静的刊物卷首，作者、发布、更新、阅读时间及主题关系集中为一行题记；真实封面保持原色，以横向开篇影像衔接标题与正文，不使用高耸卡片式封面。无封面文章直接进入正文，不制造空洞占位。

正文固定在约 `700px` 的窄列，首段、章节标题、引语、代码、公式、脚注和正文图片都以长时间阅读为先。宽屏目录作为左侧页边批注，当前章节使用深蓝短线提示；中等与手机屏幕折叠为正文前的目录抽屉。阅读进度保持在视口顶部，但不能覆盖顶栏或制造大面积色块。篇末标记、回应、上一篇／下一篇、相关阅读、共同记忆和评论依次位于正文之后，视觉强度逐级降低，不与文章主体争夺注意力。

正文文本／代码块顶部常显语言标记与“一键复制”，手机保留至少44px操作热区；长块滚动时工具栏停留在全局顶栏下方，内容横向滚动不带走按钮。复制保留原文的换行、缩进与块内 Markdown 围栏，不包含块外标记或按钮文字；成功就近显示“已复制”并向读屏播报，失败保留重试与“选中全文”入口。未指定语言的文本块同样提供复制。

阅读设置在宽屏侧栏与窄屏卷首共用字号和主题状态；宽度小于1360px时，在卷首上方保留轻量“阅读设置”入口，展开后提供16–24px字号、恢复默认和纸色切换。手机使用底部面板，中等屏幕使用锚定菜单，宽屏继续在侧栏展开。调整时保持设置展开，当前字号即时显示，恢复默认后显示“默认”。手机与中等屏幕设置层使用至少44px操作热区，菜单内触控不因失焦而提前关闭，支持Escape、点击外部关闭和焦点恢复，不增加固定阅读底栏。

随记详情页是一张带日期的生活手账页。日期在桌面作为左侧页签，纸飞机线稿只点明“偶然记下”的轻盈感；作者、发生时间、可选标题、地点和心情构成开头，正文和原色影像共享稳定的窄列。无标题随记不得显示“未命名随记”，也不能为缺失标题留下大片空白；无图随记直接进入关联信息和回应。有图时保持原图比例，不用文章封面的横向裁切。合集前后记录以连续时间线呈现，共同记忆和评论依次收束在正文之后。手机端把大号日期与纸飞机线稿（约 116px，带“A passing thought.”手写句）合为一条轻量页签，所有正文和操作恢复为单列。

#### 接着写：后来的自己接上从前的自己

「接着写」和转发按钮一样挂在要接的那篇帖子上：帖子详情的互动栏和“我的帖子”的操作区，只有作者能看到。写作页顶部用一条靛蓝短线写明“接着《…》写 · 隔了两个月”，来源固定，不提供解除，只能“放弃这篇”。来源是一段书页引文，不做卡片：靛蓝短线、标题、一句摘录和署名。文章开头另有一行来源，文末放引文；随记只在正文后放引文。间隔按两篇的发布时间写成“隔了两个月”，不写“两个月前”，以免日后读着过时。原帖的互动栏下方是“后来”列表，用细线分行，左列写“两个月后”“半年后”。一串帖子只显示上一篇，不嵌套。目录行只多一行靛蓝小字，仍是连续目录行。来源不在时只留一行灰字，靛蓝短线退成细线，不露出标题和作者。

「提到这篇的」排在「后来」之后，用同一套细线目录：左列写间隔，中间是标题和一句灰色引号里的原话，右侧是作者（与本文作者相同时省略）和类型。阅读页里的站内链接在精细指针悬停约 0.3 秒或键盘聚焦时，浮出一张 320px 的纸面预览：类型与日期、标题、三行摘录、作者；浮层带轻阴影，不可点击，滚动、移开或按 Escape 即收起，减少动态时不做淡入。触屏不出现预览。

### 个人主页

个人主页以“人物封面、公开题记、记录目录、共同书册”组织。头像使用直角人物影像；未上传头像或头像暂不可用时，统一使用映墨墨团默认头像（`/ink-app-512.png`），保持角色完整，不裁切；已上传头像仍按原图展示。昵称、账号、简介和地区是主要身份信息，可见内容与共同合集数量只作为旁注。本人编辑入口保持明确，但不抢过姓名和简介。

该成员的文章与随记按发布时间混排为带编号的连续目录，文章突出标题与摘要，随记突出正文与发生时间，原色缩略图在桌面位于右侧、手机位于文字下方。共同合集使用小型书架结构和无封面书册占位。无简介、无头像、无可见内容或无共同合集时都使用真实简洁文案，不用空卡片填充；所有数量和内容仍以访问者当前权限为准。

### 写作与操作页

文章阅读设置以可手动输入的字号框为主，加减按钮作为辅助；桌面侧栏和手机菜单共用同一状态。字号接受16–24px整数，输入期间保留草稿，回车或失焦后应用，超出范围自动取边界、小数取整；清空或“恢复默认字号”移除个人字号覆盖，让正文跟随当前设备的默认字号。输入框使用16px文字，保留原生数字键盘、可见焦点与本机记忆。

写作页像一张可工作的书桌，不做品牌拼贴。保存状态、预览、发布范围和错误优先于装饰。设置、个人管理和后台可以提高密度，但继续使用暖纸、宋体、细线和同一按钮规则。

工作页标题使用 28–32px，不放开场插画；通知、续火花等页面以工作内容开场，墨团只留给空状态或至多一幅小场景。

手机资料页的当前头像以64px预览与选择操作并排，昵称等表单进入首屏；选择新图片后展开当前与待确认头像的对照，不压缩确认、取消及错误反馈。手机个人主页保留小头像和完整昵称。个人空间的六个入口在手机上是两列无框小图：每格上方一幅约 118px 的桌面同款线稿，下方是标题和靛蓝数量，整格是同一个链接；不显示“01 / 内容”眉题，格与格之间只用留白，不画横线。合集卷首先呈现添加、管理与成员分享入口，其中只有“添加记录”是墨色实底，“管理合集”退为靛蓝文字按钮，首屏不堆叠带边框的按钮；说明及创建者、整理日期放入可展开的“合集信息”；桌面保留完整卷首。

通知页是按“今天／昨天／具体日期”分组的连续目录：头像、以成员名开头的一句话、引用原文和时间。未上传头像的成员在这里使用矢量墨团，以适配深浅主题并在 36px 下保持饱满。未读只用头像角上的深蓝小点和更深的文字，不使用底色或色边；整行可点，打开即已读，“标为已读”在桌面悬停或键盘聚焦时出现，触控常显。目标不可访问时不显示成员名，使用服务端的中性文案。

续火花页沿用个人中心版式：标题后只用“每日问候／抖音账号／后台服务”三项说明一次状态，再以细线和留白分隔步骤，不铺灰色面板。尚未连接或尚无联系人时不展示搜索、筛选和批量操作，只说明下一步。同一步只有当前该做的动作是实心墨色：未通过检查时是“模拟运行”，通过后是“开启”；不可用的按钮统一为描边样式，原因写在旁边。

续火花的扫码、搜索、播放、暂停、发送、完成和异常等功能图标共用24px坐标、1.65px圆头描边，显示为16–18px；状态同时保留文字，不用字体勾号、加减号或单个圆点代替不同任务结果。折叠入口使用一致的几何箭头，图标不独立缩小按钮热区。页头小场景使用项目内透明粗墨位图：火柴盒的抽屉连续展开成信纸，两位墨团接递同一张纸，靛蓝只落在火柴头与信封折线。问候预览用粗墨信封，使用须知用未点燃的火柴与盒体，轮廓通过实墨侧面与开放纸面形成轻重。手机继续隐藏页头和预览插画；深色模式下矢量使用主题墨色与纸色，位图保留透明轮廓并转换明暗。

写作页以一张完整纸页组织标题与正文，使用一层细边界和略亮于桌面的暖纸色，不叠加纸张阴影。顶部文稿栏与纸页两侧对齐，返回和保存状态组成左组，文稿信息、写作／预览、保存与发布组成右组；文稿信息通过抽屉打开。类型切换、小猫页边标记、标题、可展开摘要与正文沿同一条轴线排列，已有摘要时显示“已填写”。段落样式、撤销重做、图片、常用格式、源码切换与沉浸入口收在同一条工具栏，使用明确分组和统一操作尺寸。手机工具栏在同一容器内分为两行，文稿信息、写作／预览、保存与发布固定于底部，并为操作栏和安全区预留正文空间。图片、源码、沉浸写作与素材管理保持可用。

正文“链接”按钮与 `⌘/Ctrl + K` 打开共用的暖纸选择层，默认提供“站内文章”，也可切换“网址链接”。显示文字可编辑，选中正文时保留原文字，空选区默认用目标标题。站内候选先展示最近有权阅读的文章，再按标题搜索，采用带作者和阅读范围的连续目录行，支持分页、加载、无结果与重试；选择只更新待插入项，确认后才写入正文。已有链接可修改或移除，可视编辑进入同一文稿撤销历史；源码、沉浸编辑保持同等入口。选择层保护正文选区，支持键盘、Escape 取消和焦点恢复。正文里的同源文章链接复用约820ms纸页翻转，减少动态与新标签继续沿用原行为。

“本文标题”与站内文章、网址并列，读取当前未保存文稿的一至六级标题，按正文顺序展示，标注标题层级和顺序以区分同名项，可按标题搜索。空文稿说明如何设置标题样式；已删除的目标在正文工具栏下方和链接修改层就近提示。固定标识随标题保存，可视界面不暴露 Markdown 标识，不在打开或取消选择层时改写文稿。

同篇标题跳转以约240ms快速定位和1.5秒深蓝细轮廓标明落点，为固定顶栏预留空间；减少动态时直接定位。暖纸提示提供“返回刚才位置”和关闭，约20秒后自动收起，键盘焦点在提示上时保留；手机提示位于底部导航之上。返回恢复原位置与原链接焦点，同篇定位不播放整页翻转。目录链接复用相同反馈，修改键、新标签和脚注继续保留原生行为。

可视编辑中的正文与图片属于同一份连续文稿，图片前后不建立固定最小高度的独立编辑框。图片之间保持自然段落间距；图片操作浮于图片内，在悬停、选中或键盘聚焦时出现，不额外占用正文高度。点选图片后支持 Delete／Backspace 删除、Enter 在下方起段、Shift+Enter 在上方起段，以及文内剪切、复制、粘贴、拖动与撤销；同一次选区可以包含文字和多张图片。图片设置、图注、尺寸与对齐继续可用，Markdown 源码仍使用既有媒体标记，图片文件与访问权限保持既有规则。

标题上方保留一条小猫行走的横线，复用文章页已确认的线稿、五姿势循环和鼠标追随行为，不在编辑区叠加另一幅桌面插画。小猫不进入正文、不遮挡输入、不拦截指针，也不出现在发布预览与沉浸写作中；触控和减少动态模式保持静态。装饰不能影响自动保存、离线恢复、冲突反馈、媒体插入或发布权限。


## 8. 动效与无障碍

- 帖子收藏采用原生五角星，与表情回应并列；空心墨线表示未收藏，成功保存后填成靛蓝，以约280ms的轻弹和短墨线反馈一次，取消收藏回到空心。文章阅读侧栏复用同一图案与状态。已收藏时保留“我的收藏”小链接，跳转`/me/favorites`，取消后收起；链接保持原生键盘和新标签行为，不自动消失或抢焦点。请求中阻止重复提交，失败保留原状态并就近说明；初始读取、键盘操作及减少动态时不播放弹跳。
- 手机首页时间流的记录可以“拿起来”（只在手机宽度与触屏启用，是现有收藏、回应按钮之外的快捷方式）：按住约 0.26 秒，纸从桌面浮起（轻抬 4px、放大 2%，借用浮层阴影并向四周露出 12px 纸边）；横向拖动时纸跟着手指走并随位移轻微倾斜，超过约 96px 后有阻尼、最多 140px。右拖露出靛蓝星形“收藏”（已收藏时为“取消收藏”），左拖露出“回应”；越过约 76px 时提示加重、支持震动的设备轻震一次，此时松手才执行，不够则弹回（约 260ms）。右拖收藏成功后在记录右上角盖一枚小星并给出“已收藏／已取消收藏 · 撤销”，左拖打开回应底部面板（六种回应三列排开，已选的以靛蓝线框标出，再点一次取消），选择后给出“已回应：喜欢 · 撤销”。竖向滑动照常滚动；起点贴近屏幕左右 24px（系统返回手势）、落在图片、视频或按钮上时不接管；拿起或拖过的记录松手后不当作点按打开；拖动中不显示链接按压变淡。时间流上方用一行文字说明手势，点“知道了”或第一次成功使用后不再出现（偏好存在本机浏览器）。减少动态时保留手势，只取消倾斜、放大与小星。
- 详情页与收藏列表取消收藏后，提供最近一次操作的“撤销”与关闭入口，不用短倒计时催促。提示位于底部导航或键盘操作栏上方，撤销确认成功后才恢复收藏状态；失败保留撤销入口并说明原因。收藏写入携带明确目标状态，重复请求不会反向切换。
- 手机小图标、文字操作、筛选与视图切换在按下时以轻微墨色底反馈，松开或取消后恢复；文字、图标和热区不位移。主按钮与已确认的收藏、回应、底部导航动效沿用各自反馈，减少动态时仍保留即时颜色状态。
- 常规动效时长 `120–200ms`，只用于状态切换、菜单和反馈。
- 从首页、文章目录或其他站内文章链接进入详情时，沿用右下角向左上翻开的纸页动效，约820ms。冻结当前可见页面，保留滚动后的页眉与底部导航位置；新详情页在下方正常加载，标题与封面不再叠加共享元素动画。目录返回继续恢复原筛选、页码和条目位置。刷新、直接打开地址、修改键打开新标签不播放；减少动态时直接导航。返回或窗口变化立即释放副本与交互锁。
- 图片灯箱以直接操控为准：单指或鼠标拖动时图片实时跟随，水平拖动可浏览相邻图片，竖向拖动可关闭；双指以手势中心缩放，放大后可平移，双击／双点可在原尺寸与放大之间切换。未达到操作阈值时在 `180ms` 内回位，边界拖动有阻尼；减少动态效果时回位即时完成。键盘和显式按钮始终可用。
- 文章页与写作页沿线小猫是由鼠标触发的局部装饰例外，按上述跑步周期执行；到达目标即停，不自动巡游，不将此例外扩展为全站持续动画。
- 不使用持续漂浮、视差或无意义入场动画。唯一的列表例外是手机首页时间流的“纸页落座”，它绑定滚动位置而不是时间：记录或插页从底部导航上沿露出时是一张略低（约 64px）、略斜（约 3°）、略小（95%）、偏淡（25%）的纸，以左下角为落点；手指往上推多少它就升起摆正多少，到它的下沿越过底部导航上方约 180px 时完全落定；手指停它就停，往回拉又退回去。用浏览器原生滚动时间线（`animation-timeline: view()`）在合成线程运行，不用脚本监听滚动；按时间播放的入场动画会在导航后面播完、不跟手，不再使用。只在手机宽度启用；不支持滚动时间线的浏览器、减少动态和打印时保持静止。动画只改透明度与变换，不改变排版、滚动位置和点击区域。
- 支持 `prefers-reduced-motion`。
- 合集目录进入详情时（从书架介绍卡点“进入合集”，或书架以外的书册直接点开），书册从所在位置轻抬、移到屏幕中央，再沿书脊翻开到完全摊平，共约 1.2 秒，翻开时整册保持居中，摊平后淡出并衔接详情页。光影随翻转角度变化：封面转走时外缘变暗，内页从暗转亮，底页先接住投影再散开；这组渐变只存在于翻开的约 0.7 秒内，是“不使用渐变”的局部例外，不扩展到静态页面。左页显示卷号、简介和署名，右页显示合集名称；透视按书宽换算，手机与桌面的立体感一致。导航与真实加载并行，不等待动效。标题与封面链接均可触发，修改键打开新标签保持浏览器原生行为；减少动态时直接导航。临时书册无交互并从读屏树移除，超时、缩放、用户滚动、下一次操作或页面隐藏立即释放。
- 媒体灯箱采用“拿起与放回”的照片连续性：从点击的缩略图原位展开约 380ms，关闭时从当前照片位置回到该照片的可见缩略图，约 260ms；使用等比缩放和裁切，避免照片变形。切换图片后匹配新图片的缩略图；缩放、手势、键盘、直接链接、分页和权限错误沿用真实灯箱逻辑。关闭和还焦点立即执行，视觉副本单独完成；原位不可见、减少动态或浏览器不支持时直接开合。
- 删除即揉纸：在“我的内容”确认删除且服务器成功后，这一行先起皱并出现墨线折痕，再收成带翘起纸角、叠压纸面与深折缝的小纸团（64px，约440ms），落下翻转淡出（约260ms），随后收起占位让下面的记录补上；写作页“放弃这篇”删除成功后，整张写作纸在可见区域中央揉成纸团再离开。删除失败不播放，减少动态、页面隐藏或元素不在视口时直接移除。纸团使用透明粗墨插画，保留笔压、枯笔留白与折缝积墨；纸面和墨迹分别采用当前页面的纸色、墨色，深浅主题保持相同的纸张结构。收拢的外缘与插画纸角对齐，成团后撤去临时几何墨边，只留下插画自身的透明轮廓。不加阴影和渐变，动画中的行不接收指针。
- 首页快速随记以便笺展开/收起，约 260/200ms；仅主动切换状态时舒展纸面，不随每次输入或草稿恢复播放。入口左侧使用原生 SVG 的折角便笺与落笔钢笔，墨色轮廓配少量靛蓝笔箍和墨迹；桌面 36px、手机 32px，静态显示并从读屏树隐藏。收起保留草稿并还焦点，发布成功才收回便笺、将新随记加入时间轴并短暂点亮，失败继续保留编辑内容和错误原因。开发环境 `/dev/paper-motion` 提供共用引擎的四项示例，揉纸包含原尺寸、放大细节与慢放对照，不执行内容删除；生产包不包含该预览。
- 文字化墨点：欢迎页点“进入映墨”或页眉“登录”时，标题、导语、三段说明和推门插画从左到右逐格剥落成细小墨点，顺风向右上飘散约 0.5 秒，欢迎页其余部分同时隐入纸色；随后进入登录页，墨点约 0.7 秒聚成登录页右侧捧书墨团的真实轮廓，再与纸色遮罩一起淡出，露出原位的墨团，全程约 2.3 秒。目标墨团找不到时聚在画面中部后淡出。文章正文与图集之后放一行文章标题和“全文完”，读者滚到文末、整行完全进入视口时只播放一次：标题化成墨点，聚成读书墨团（约 1.6 秒）后留作结尾小图。墨点为当前主题墨色的原生 canvas 圆点，只有一个墨色、三档浓淡，不加阴影和渐变。修改键、新标签与减少动态保持原生导航，文末直接显示墨团；缩放、返回、页面隐藏立即结束并完成导航，超时释放，画布不接收读屏。开发预览 `/dev/ink-passage` 可反复播放两段，生产包不包含该页面。
- 手动切换深浅主题采用一次约 560ms 的墨迹晕染：从触发按钮中心扩散，沿不规则墨边显露真实的新主题；浅色为暖纸白，深色为现有墨黑。通过浏览器页面快照与动态遮罩保持正文、照片、输入内容和滚动位置，不反转图片、不复制表单。文章标题与封面的独立转场名在此期间临时停用，完成后恢复。原有“跟随系统／浅色／深色”保留，实际颜色不变、初次加载及系统自动换色不播放；连续选择、滚动、缩放、离开或减少动态偏好变化立即结束。缺少 View Transitions 的浏览器直接换色。开发预览 `/dev/theme-ink` 使用同一主题上下文，可反复比较黑墨、白墨、照片及未保存文字；生产包不含此页。
- 键盘焦点始终可见；不得移除轮廓后不提供替代。
- 正文、元信息、链接和状态色必须满足可读对比度。
- 图片提供真实替代文本；装饰图片和手写标记从读屏顺序中隐藏。
- 表单错误使用 `aria-invalid` 与关联说明；异步状态使用适当的 live region。

## 9. 禁止项

- 冷灰背景、纯白大底、纯黑大底。
- 渐变、玻璃拟态、发光、拟物厚阴影。
- 大面积蓝色、第二品牌强调色。
- 卡片墙、圆角面板套圆角面板。
- 胶囊式主导航和胶囊标签泛滥。
- 为制造“高级感”而降低文字对比度或字号。
- 每个页面各写一套近似颜色、按钮和页头。
- 把登录页的拼贴和手写装饰复制到所有操作页面。
- 为了匹配原型而隐藏真实产品能力或伪造不存在的功能。

## 10. 实施与验收

统一顺序：

1. 合并全局变量与基础控件。
2. 重构桌面顶栏和移动端底部导航。
3. 完成首页、文章详情、合集详情三张样板页。
4. 迁移文章、随记、漫游、归档与个人内容页。
5. 最后统一写作、通知、设置和管理后台。

每个阶段同时检查 `390 × 844` 与 `1440 × 900`：

- 登录进入首页时没有明显的色彩、字体或控件跳变。
- 页面只有一套背景、文字、线条和强调色。
- 页面样式限定在各自的根节点；共用卡片不能因先前访问过的页面而改变布局，刷新与站内跳转应保持一致。
- 同一内容边界没有重复横线；移除装饰后，仍能通过留白、对齐和标题读懂结构。
- 文章页小猫造型与线稿原型一致，左右追随、转身、停步和边缘限制正常；触控与减少动态模式保持静态，装饰不遮挡阅读或操作。
- 首要任务在首屏可发现，主要操作清晰。
- 长标题、长昵称、有图、无图、空数据和错误状态均不破版。
- 手机无横向滚动，底部导航不遮挡内容。
- 键盘、读屏、触控和减少动态模式可正常使用。
- 页面功能、权限、URL 状态、保存与上传流程通过原有测试。

原型截图用于检查气质和信息层级，不作为逐像素实现要求。若原型与真实数据、交互或本文冲突，以真实产品能力和本文为准。
