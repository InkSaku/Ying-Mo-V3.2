# 写作、发布与主题：一次完整升级

## 范围与验收

- 真正的可视编辑：Markdown 标题、强调、列表、引用、代码与表格呈现为可编辑的格式。
- 源码可直接编辑，并提供安全实时预览；切换模式不丢失内容。
- 保留内部图片上传、粘贴、插入位置、排序、图片设置、自动保存和撤销重做。
- 发布前用已审阅的线稿窗口集中选择合集、标签和阅读范围。
- 保留当前选择；取消后仍保存选择；失败后可在窗口重试；普通保存不弹发布窗口。
- 合集只提供有权投稿的选项，共同回忆的合集范围继续锁定。
- 默认推荐引用最多的前十标签，搜索覆盖其他可用标签；名称规范化去重。
- 新标签在保存内容时创建或复用，取消输入不会产生空标签。
- 每个已有标签显示当前成员可见的引用数；标签选择与查看分区分开操作。
- 接入三幅新线稿，更新主题索引与分区，适配手机和深浅主题。

## 约束

所有计数继续遵守读取权限；后台与私密内容不用于扩大主题发现范围。
保留 Markdown 为保存格式，不迁移既有文章，不改文章网址。
对编辑器暂不能表示的高级 Markdown 保留原文编辑块，不能静默删掉公式、脚注或 HTML。
