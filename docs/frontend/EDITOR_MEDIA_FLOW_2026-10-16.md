# 写作图片连续编辑验收

日期：2026-10-16。

原先图片两侧分别挂载独立文字编辑器，每段文字都有最小高度和段落工具栏。空文字段也占据高度，图片无法参与同一个选区与撤销历史。

现在可视编辑使用单个 Tiptap 文稿，站内图片是可选中、可拖动的媒体节点，仍以 `[[ym-media:ID]]` 保存。旧正文不需要迁移。图片工具栏浮在图片内，在悬停、选中或键盘聚焦时显示；图注、尺寸、对齐、受保护图片读取与图片设置继续保留。

支持点选后 Delete／Backspace 删除，Enter 下方起段、Shift+Enter 上方起段，文内图片和混合图文的复制／剪切／粘贴、纯文本媒体标记粘贴、拖动位置与撤销。删除只移除当前正文节点，不删除媒体文件。源码修改和上传插入独立进入撤销历史，避免撤销删除时连带撤回上一笔源码修改。

验证结果：

- `npm run lint` 通过。
- `npm run test:run`：159 项通过，包括媒体与代码、公式等 Markdown 的往返保留。
- `npm run build` 和 `npm run verify:bundle` 通过；最大首次路由为 276.91 KiB gzip，低于 300 KiB。
- 编辑器定向 Playwright 回归：4 项通过，覆盖原有插图位置、图片设置与排序、Markdown 格式、沉浸写作，以及新增删除／撤销、上下起段、原生剪贴板、图文混合选区、拖动／撤销、自动保存与刷新。
- 桌面及 390px 手机截图已检查；连续两张图片的间距不超过 48px，未发生水平溢出。设计机械扫描未发现问题。

扩展运行 `writing-flow.spec.js` 时另有两项文案选择器不匹配：标签页测试查找“这个主题下还没有可见内容”，当前页面使用“这个主题下暂无可读内容”；手机发布测试查找“登录成员”，当前发布对话框使用“所有映墨成员”。两处页面不在本次修改范围，未调整其业务实现或测试。完整发布流程不能据本次结果宣称全部通过。

本次验收覆盖同一文稿内的图片移动与复制，不包含跨 Post 复制媒体绑定或粘贴图片到 Word 等外部软件。未执行部署。
